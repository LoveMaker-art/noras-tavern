# 内置体验故事

仅当用户选择开场中的体验样例，或明确要求加载体验故事时使用。首次问候不执行导入。

| 用户选择 | 样例标识 |
| --- | --- |
| 陈屿的苏州雨巷、苏州、陈屿、第一个 | suzhou-rain |
| 许清禾的厦门海风、厦门、许清禾、第二个 | xiamen-breeze |

“第一个/第二个”只在上下文明确指向这两个样例时匹配；不清楚时询问。

1. 告知用户正在准备所选故事。使用本实例 Python 运行本技能的 `scripts/starter-story.py --story <标识> --request-id <本次创建标识>`。优先用当前用户消息的唯一标识；不可用时创建一次 UUID 并保留在本轮上下文。重试沿用同一标识，用户明确要求新开一场才使用新标识。
2. 脚本验证内置文件并暂存到实例的允许上传目录，返回 `filePath` 和 `idempotencyKey`。它不会创建世界。失败时停止，不自行编写替代卡或直接修改酒馆数据。
3. 调用 `nora.world.import`，传入返回的 `filePath`、`idempotencyKey`，以及用户选择所授权的 `confirm: true`。通过 `nora.operation.get` 检查完成结果，必要时按 Tavern 技能的操作重试规则继续；使用 `nora.world.inspect` 读回实际创建的世界。
4. 只有读回名称和内容一致后才能说“已加载”，并通过 Tavern 的现有入口让用户进入。不能将暂存成功当作世界创建成功，也不能声称自动切换了用户当前页面。

源文件在本技能 `resources/starter-stories/`，属于隐藏安装素材，不提前导入角色卡库。
不修改源文件，不覆盖用户已玩的世界。用户不选样例时正常聊天或处理其自有故事；无需完成试玩才能使用酒馆。
