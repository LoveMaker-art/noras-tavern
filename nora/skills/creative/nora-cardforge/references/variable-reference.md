# 变量与参数字典

用于回答“这个变量是什么、现在多少、为什么变化、能不能改”。这里只定义本地
编译器的行为；每张卡的剧情语义必须查该卡，不从变量名称补写规则。

索引：分类；逐变量说明；MVU 参数；类型；更新规则；脚本符号；示例；问答检查。

## 先分清对象

| 对象 | 示例 | 不要混淆成什么 |
| --- | --- | --- |
| 剧情状态 | `stat_data.角色状态.信任` | 作者自定义的数据，不是酒馆统一规定的“好感度”。 |
| 声明元数据 | `data.extensions.cfMvuVarGroups` | 编辑和生成用的分组、类型、默认值，不是当前进度。 |
| 初始化值 | `features/mvu.json` 的 `default`、初始化世界书 YAML | 初始设定，不是某个聊天当前已保存的值。 |
| 提示规则 | 世界书中的“每次最多增加 3” | 给模型的要求，不等于程序已实施增量限制。 |
| 显示值 | 状态栏读取结果、`_.get(..., 0)` 的回退值 | 显示 0 也可能是路径未找到，不能据此证明状态已初始化。 |
| 派生值 | 脚本用信任计算出的阶段/标签 | 必须找到公式和触发点；名字带 `_` 不会自动生成公式。 |
| 插件配置 | `keepFloors`、`markdownOnly`、脚本 `data` | 控制程序行为的参数，不直接代表角色心情或剧情状态。 |

酒馆助手接口存在不同变量作用域；读取函数及其参数决定来源，不能把所有变量都
叫作全局变量。`getAllVariables()` 的合并视图也不是所有作用域原始存储的完整清单。
见 [酒馆助手变量接口](https://n0vi028.github.io/JS-Slash-Runner-Doc/guide/功能详情/变量/获取变量.html)。

## 每个变量怎样解释

概念问题可举例并标明假设；具体卡片按以下字段取证，用自然语言回答，不必机械输出
长表。用户要求“全部变量说明”时，为每个变量保留这些信息；未知项不要省略。

| 项目 | 必须查明或标记未知的内容 |
| --- | --- |
| 路径与来源 | 完整路径、声明文件/条目/脚本位置，是否只有引用却没有定义。 |
| 中文含义 | 谁的什么状态、单位、业务含义；同名不保证同义。 |
| 类型与允许值 | 数字/文字/枚举等，边界是描述约定还是运行时约束。 |
| 默认与当前 | 分开列；当前值需带聊天/消息/分支或 swipe、读取时点、数据来源。没有快照就说未读取。 |
| 更新者与条件 | 模型补丁、初始化器、脚本、用户手改中的哪一种；何时更新、依据哪条规则。 |
| 使用者与影响 | 哪些世界书、条件分支、输出模板或状态栏读取它；无消费者时说明未找到用途。 |
| 修改与删除 | 改初值、改实时值、改路径三种行为分别影响什么；是否有依赖需要同步。 |
| 证据与缺口 | 已确认、推断、未定义、相互冲突分别标注，附实际路径/JSON 键或源码位置。 |

沿“声明/初值 -> 更新来源 -> 使用位置”追踪。`cfMvuVarGroups` 只覆盖本编译器的
声明格式；导入卡可能只在脚本、EJS、初始化条目或运行快照中声明变量。不要因缺少
该扩展键就断言没有变量。动态计算的路径或外部模块未取得时，列出发现范围及缺口。

定义、Schema、更新规则和显示名称不一致时，列出冲突，不悄悄选一个解释为事实。
原工程与已导出卡不同也分别说明；卡文件里的初值无法证明既有聊天状态。

## MVU 声明参数

`features/mvu.json` 可为 `{ "variables": [...] }` 或直接的数组。每项参数如下：

| 字段 | 默认/形式 | 实际作用与边界 |
| --- | --- | --- |
| `group` | 缺失或空字符串时为 `其他` | 分组名，也是状态对象的一层键。不会像 `field` 一样拆分点号；建议分组名不用点号。纯空白分组会被跳过。 |
| `field` | 无有效默认值 | 变量名；空白项被跳过。`关系.阶段` 会生成嵌套键，不是一个带点的字面键。 |
| `type` | `string` | 决定生成的类型和初始化方式，见下表；未知值目前退回字符串处理，不能把这种接受当成支持。 |
| `default` | 未给时空字符串 | 初始值来源之一；最终值受 `type` 转换影响。不是每轮重置值。 |
| `defaultValue` | 优先于 `default` | 非 null 时覆盖 `default`，归一化为字符串；两者冲突须明确说明。 |
| `min` / `max` | `null` | 数字上下界；写入规则文本。只有同时配置 `clamp` 才生成裁剪转换。不是每次增减幅度。 |
| `clamp` | false | 对 number 且至少一个边界非 null 时，生成 `_.clamp` 转换。单边未填的另一侧使用 -999999 或 999999，并非无穷。 |
| `enumValues` | 空字符串；值用逗号分隔 | 枚举候选文字，如 `陌生,熟悉,信赖`。不是数组或范围表达式，建议明确指定其中一项为默认值。 |
| `recordFields` | 空字符串 | 当前仅存入元数据，生成器未用它约束 record 子字段；不能承诺它定义了对象结构。 |
| `description` | 空字符串 | 生成给模型的 `check` 规则。缺失时只有按类型生成的泛化提示，不会自动理解作者未写的剧情机制。 |

输出元数据使用 `group.name` 和 `fields[].name`；其中的 `showAdvanced: false`
是归一化时固定写入的展示元数据，没有已实现的剧情/权限作用。不要把输出元数据
直接当成同结构的 `variables[]` 输入。避免重复路径、父子路径碰撞及点号空段；
当前生成器不是完整的冲突校验器。

### 各类型当前能表达什么

| 类型 | 初始化及 Schema 行为 | 不能承诺的能力 |
| --- | --- | --- |
| `string` | 使用字符串默认值，缺省空串。 | 不自带长度限制、正则校验或枚举限制。 |
| `number` | 初值用 `Number(defaultValue) || 0`；Schema 生成 `z.coerce.number()`，可附 clamp。 | 不自动限制整数、每轮 delta 或剧情合理性；非法初值可能被回退为 0。 |
| `boolean` | 归一化后的默认字符串只有 `true` 得到 true，其余为 false；Schema 为 `z.boolean()`。 | 不把 `yes`、`1` 当 true，也不代表任意运行时字符串都可自动转成布尔。 |
| `array` | 生成字符串数组 Schema；初始化固定 `[]`。 | 当前忽略非空默认数组，不支持通过此规格声明对象数组或数字数组。 |
| `record` | 生成动态键到字符串的映射；初始化固定 `{}`。 | 当前忽略非空默认对象，`recordFields` 不能生成嵌套的强类型对象。 |
| `enum` | 非空 `enumValues` 生成字符串枚举。Schema 缺少默认值时会选首项。 | 初始化 YAML 在未指定默认值时仍为空串，可能与 Schema 不一致；空候选会退回字符串逻辑。 |

Schema 中的 `prefault` 是缺值时提供的输入回退，不是覆盖每轮已有值的操作。
此表描述生成代码；约束真正执行还需要目标 Schema 注册与 MVU 处理链成功运行。

## 更新与读取

典型链路是：作者声明变量与规则，模型据规则提出更新命令，目标 MVU 解析并应用，
Schema 参与约束，消费者读取结果。哪些环节实际存在要查卡及运行时，不把示意链路
当成已验证的部署行为。

- `stat_data` 是 MVU 状态数据容器，不是特定剧情变量名称。
- HTML 中 `stat_data.角色状态.信任` 是读取路径；补丁里的斜杠路径与它不是可随意
  互换的字符串。根节点约定、转义和操作支持需核对目标解析器。
- 本生成器要求 `replace`、`delta`、`insert`、`remove`、`move` 风格的更新；其中
  `delta`、`insert` 是扩展约定，不能宣称输出就是严格 RFC 6902 JSON Patch。
- 生成的 `<Analysis>` 是更新说明字段，不是变量存储或模型内部推理的可靠记录。
- `_` 前缀只触发提示层的“不写”约定，并使该字段不进入生成的逐变量规则。
  Schema 仍包含字段；没有自动只读权限、派生公式或写入阻断。
- `description` 中的“每轮最多 +3”“80 以上进入信赖阶段”是文字规则，除非另有
  具体代码或条件分支，否则分别只是模型约束意图，不是强制限幅或自动阶段切换。
- 静态状态栏路径检查依赖 `cfMvuVarGroups` 与字面 `stat_data.xxx`；计算属性、
  拼接字符串等不一定被扫描。检查通过不是所有变量读取都正确的证明。

改默认值会改变后续构建的初始定义，不会自动更新已存聊天。改实时值属于运行状态
写操作；改路径要同步 Schema、初始化、更新规则、模板和脚本引用。解释或评估影响
不自动授权上述修改，更不授权重置进度。

### 脚本里的常见符号

下列名称出现在本生成器或 [附带的状态栏样例](../fixtures/statusbar.html) 中。
表格说明其在这些代码中的用途，不证明目标环境已提供或成功调用该接口。

| 名称 | 在这里的作用 |
| --- | --- |
| `Mvu` | 变量系统的运行接口对象；与存放剧情值的 `stat_data` 不同。 |
| `Mvu.events.VARIABLE_UPDATE_ENDED` | 样例监听的更新结束事件，用来重新读取并呈现状态。 |
| `getAllVariables()` | 获取合并的变量视图供样例读取，不是修改变量的命令。 |
| `all_variables` | 样例接收读取结果的局部变量名，不是额外创建了一份永久剧情状态。 |
| `waitGlobalInitialized("Mvu")` | 样例在访问 MVU 前等待对应全局对象初始化；不代表聊天里的每个状态字段都存在。 |
| `eventOn(...)` | 样例注册事件回调；实际回调在事件发生时才执行。 |
| `errorCatched(init)` | 对初始化函数的错误处理包装；不等于能自动修复插件缺失。 |
| `populateCharacterData()` / `init()` | 样例作者定义的渲染及初始化函数名，不是固定剧情变量或通用插件 API。 |
| `z` / `Schema` | 类型构建接口与生成的结构定义；不是当前状态值。 |
| `registerMvuSchema(Schema)` | 把定义交给导入的注册器；调用成功和约束执行仍需运行证据。 |
| `_` | 此处供 `_.get` 读嵌套路径、`_.clamp` 裁剪数值的工具库对象，不是字段名的只读前缀。 |
| `$` | 此处用于页面初始化、选取元素及设置文本的 jQuery 接口；例如 `.text(...)` 只改显示。 |

若导入卡复用这些名字但声明了不同对象，以它的绑定和调用代码为准。

## 面向用户的回答示例

假设卡片实际声明如下，尚未取得聊天快照，也没找到阶段切换代码：

```json
{
  "variables": [
    {
      "group": "角色状态",
      "field": "信任",
      "type": "number",
      "default": 20,
      "min": 0,
      "max": 100,
      "clamp": true,
      "description": "表示角色对用户可靠性的判断，不代表恋爱好感。履约后可增加，背叛后降低；每轮最多增加3。"
    }
  ]
}
```

用户问：“信任是什么？现在有多少？到 80 就会恋爱吗？”

> 这张卡的“信任”表示角色认为你是否可靠，定义明确说它不是恋爱好感。
> 路径是 `stat_data.角色状态.信任`，初始值是 20；我没有读取当前聊天快照，
> 所以不能把 20 当成现在的值。
>
> 作者要求履约后增加、背叛后降低，每轮最多增加 3。0 到 100 的范围有生成的
> clamp 代码，但“每轮最多 +3”目前只是给模型的文字要求，未发现硬性限幅。
> 也未找到到 80 自动恋爱或切换阶段的逻辑，不能做这个承诺。

实际回答附该卡的具体文件/条目证据，而不是引用示例当作用户卡片的定义。
若只看到字段名“信任”且没有描述，应说“从名称推测与信任有关，衡量对象和规则未定义”。

## 问答检查

用于维护技能时的人工回归场景，不代表已做独立模型或目标运行时测试。

| 用户问题 / 已知条件 | 合格回答必须包含 |
| --- | --- |
| “现在信任多少？”只有默认值 | 初始/当前区分；说明缺少对应聊天快照。 |
| “只填 min/max 能保证不越界吗？”clamp false | 本生成器未生成边界转换；另有运行代码时再另行判断。 |
| “`_阶段` 谁算出来？”没有公式 | 仅命名约定；没有找到计算来源，不能编造阈值。 |
| “把默认值改高，会改旧聊天吗？” | 只影响构建定义；旧状态变更需另外确认运行流程与授权。 |
| “没 cfMvuVarGroups，是不是没变量？” | 不能确定；还需查脚本、初始化、模板等来源。 |
| “关状态栏是不是就没有变量了？” | 显示消费者与状态更新者不同；检查实际依赖后说明影响。 |
| “keepFloors=3 是删除三楼之前的数据吗？” | 生成的是提示层过滤，非历史变量删除。 |
| “把所有变量说明白。”有未知插件/动态路径 | 逐项来源清单、定义与引用、未知项及覆盖缺口；不能假装枚举完整。 |

[MVU 生成器](../src/mvu/mvu-compiler.js)、[状态栏检查](../src/statusbar/statusbar.js)。
`stat_data` 的上游定义见 [MVU 作者源码](https://github.com/MagicalAstrogy/MagVarUpdate/blob/beta/src/variable_def.ts)；
其 beta 分支不证明目标环境的版本与行为。
