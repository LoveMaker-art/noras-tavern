# Nora Tavern Desktop Shell

Electron 主进程和 preload 源码在这里。正式 UI 位于 `launcher/ui/index.html`，安装、更新、卸载模块归属 `deployment/`。

本目录 `package.json` 的构建路径描述**生成后的交付目录**。不要在源码目录直接运行 `npm start` 或 `pack:*`；开发命令通过根目录的 `tooling/run.mjs`，打包在发布候选目录中执行。

详见 [开发与发布说明](../../CONTRIBUTING.md) 和 [启动器职责](../README.md)。

安装失败的日志位置、记录内容和隐私边界见 [安装诊断日志](../../docs/launcher-install-diagnostics.md)。

## 产品流程

1. 读取安装位置、组件版本和实际服务状态，区分首次安装与日常启动。
2. 首次安装校验完整平台发布包，安装配套 Hermes、Nora 内容及 Tavern。
3. 验证用户模型配置。首次设置通过已有 Tavern 模型配置接口同步初始选择，不另写一套模型业务；后续模型保持各自配置边界。
4. 激活 ClawChat，完成 Liveware 注册和实际就绪检查。
5. 日常界面分别管理 Nora 与 Tavern。macOS 关闭窗口不停止服务；完全退出（⌘Q / 退出菜单，Windows 最后一个窗口关闭）先停止当前安装实例的 Nora、Tavern 与托管连接，再退出启动器。停止失败保留启动器并提示重试，不按进程名称批量结束其他实例。
6. 完整系统更新由 `deployment/update/` 管事务；卸载由 `deployment/uninstall/` 管确认、停止和安全删除。

## 启动与配置恢复

- 打开正式启动器，在安装完整、无更新/卸载任务时检查并启动 Tavern；每次页面生命周期只自动尝试一次。不会打开浏览器或自动启动已暂停的 Nora，手动停止后不会被五秒轮询重新拉起。
- 首次模型配置按“测试响应 → 保存 Hermes 配置和待同步记录 → 确保 Tavern 就绪 → 同步 → 复核”执行。同步失败后保留待同步记录，重开可继续，无需重新填写 Key 或再次请求模型。记录不含明文 Key；更换凭证后须重新验证。
- 自定义接口支持读取 `/models`，也保留手工填写。基础地址使用 OpenAI 兼容接口（如 Ollama 的 `http://127.0.0.1:11434/v1`、LM Studio 的 `http://127.0.0.1:1234/v1`），用户须自行启动模型服务。
- “无需鉴权”仅用于明确不要求 Key 的自定义服务。启动器测试不发送 Authorization；为兼容 Hermes/酒馆 SDK 的非空凭证约束，运行配置使用公开占位值 `nora-local-no-auth`，运行时可能发送这个无秘密的占位值。启用鉴权的服务仍须真实 Key。连接测试仅验证文字回复，工具调用能力未验证，不承诺任意本地模型均能执行 Nora 工作流。
- Tavern-only 启动不等待 ClawChat 注册；完整 Nora 启动仍验证 ClawChat 和 MCP。子进程结构化错误保留原始原因。
- 完全退出复用现有 `stop --service all` 及进程归属校验；停止操作最多等待 60 秒。安装、更新、模型保存期间拒绝退出，防止截断配置写入；退出期间拒绝新的变更操作，重复退出不会并发停止。强制结束进程或系统断电不属于正常退出保证范围。
- 首次安装为未设置的 `approvals.destructive_slash_confirm` 写入 `false`；保留用户显式值，不改变危险终端命令审批策略。已有安装不会因只替换酒馆文件自动获得启动器本体修复。

## 发布边界

版本查询和发布组件下载使用 Electron Chromium 网络栈，保留 HTTPS 证书校验和组件哈希校验。日志记录请求目标（不含查询参数）、网络引擎、HTTP 状态和失败原因，不记录响应正文或请求头。

本分支的候选测试包在安装前额外对照 Chromium 与 Node 的 GitHub 版本查询，并通过 Chromium 校验正式版系统清单；Chromium 检查失败会停止安装，Node 对照失败仅记录诊断。通过后安装本包内置候选资源，因此安装成功不等于远程大文件下载已在用户网络验证。测试数据保存在独立候选目录，不覆盖正式版数据。

三种运行时必须在对应平台构建：macOS arm64、macOS x64、Windows x64。发布的图像来自同一份 `launcher/ui/assets/`。Windows 的普通安装入口是 NSIS setup；不能把某平台构建成功当作其他平台通过验收。

源包和候选包不包含真实 Key、会话或开发者安装数据。核心包不包含可选的 Browser Use / Computer Use 组件。未签名或未公证的安装包可能出现系统安全提示。

布局迁移不改变现有本地候选标识、默认数据目录、语言逻辑、开场白或 UI。发布仍需分别完成授权、三平台构建与目标环境验收。
