   验证不含 Git 元数据的导出目录仍可同步、重复同步无变化、修改输入后拒绝旧快照。
4. 发布流程新增 Story Profile 源码/快照一致性检查、原生投影测试，并对整个源码
   导出检查常见密钥格式；保护范围包含新加入的 `story-profile/`。
5. 更新过期测试与文档：固定已有中文夹具语言；思考流测试使用真实账本函数；
   投影 HTTP 测试等待 MEMORY.md 结果而不是更早的 JSON 提交；UI 接口契约只检查
   mount 参数，不跨越后续 MCP 初始化误判。
6. 共享 World theme 是纯数据验证/投影，保留唯一实现。契约显式限定这一个共享文件，

7. 按仓库已有 ESLint 规则统一已接入代码的格式。未改变界面、模型选择策略、
