## 本次收敛

1. 删除旧 `ops/scripts/tavern_cli.py`、`native_tavern.py`。旧档案 CLI 仍请求已退役的
   `/api/nora-worlds/list`，当前产品调用不依赖它们。复盘预览/写入测试改为直接通过
   当前 `reflection.reflect_context` 接口；保留原模型调用次数和持久结果断言。
2. 同步脚本默认读取仓库内 `story-profile/`，Python adapter 同时支持源码布局及
   内嵌运行布局。保留显式环境路径覆盖，不隐式寻找另一个仓库。
3. 快照身份由输入内容 SHA-256 决定，避免同仓提交改变 HEAD 后快照永久变脏。
   验证不含 Git 元数据的导出目录仍可同步、重复同步无变化、修改输入后拒绝旧快照。
4. 发布流程新增 Story Profile 源码/快照一致性检查、原生投影测试，并对整个源码
   导出检查常见密钥格式；保护范围包含新加入的 `story-profile/`。
5. 更新过期测试与文档：固定已有中文夹具语言；思考流测试使用真实账本函数；
   投影 HTTP 测试等待 MEMORY.md 结果而不是更早的 JSON 提交；UI 接口契约只检查
   mount 参数，不跨越后续 MCP 初始化误判。
6. 共享 World theme 是纯数据验证/投影，保留唯一实现。契约显式限定这一个共享文件，
   并检查它无 DOM、ST、模块导入或 I/O 依赖；没有为目录表象复制第二份规则。
7. 按仓库已有 ESLint 规则统一已接入代码的格式。未改变界面、模型选择策略、
   15 轮阈值、原故事档案字段含义，未新增服务、缓存或依赖。
