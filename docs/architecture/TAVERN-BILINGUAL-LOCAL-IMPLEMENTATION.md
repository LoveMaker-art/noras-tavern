# Nora 固定文案与 ST 翻译接口：本地交付记录

日期：2026-08-30。基线：`053646a2bf65dbc6ce234ff3788d2e4648a14c12`。

## 实际范围

按用户最新要求只做两项：Nora 自有界面的固定文案，以及 ST 的文字翻译接口。

- 页面 `?lang=zh` / `?lang=en` 优先；没有有效参数时使用浏览器语言。中文家族归简体中文，其他语言回退英文。
- 没有新增语言选择按钮、宿主通知事件、自动刷新、模型翻译请求或配置轮询。
- 本轮没有操作 ClawChat 语言设置，没有改 Story Profile 的生成、存储或前端源码。
- 不承诺 ClawChat 设置切换时已经打开的页面自动更新；那是之前完整计划中被本轮明确排除的范围。

## 源码行为变化

1. `public/scripts/nora-i18n/strings.js`：345 项英文译文，以中文原文和 ST `${0}` 参数约定作为 key。覆盖启动、世界列表/创建/删除/恢复、角色卡库、角色与世界书编辑、模型/MVU 设置、消息操作、通知与思考状态。
2. `core.js`：Nora 与 ST 共用语言状态和词典；Webpack 与 import-map 模块共享同一页的注册表，避免形成两套实际数据。词典不读写业务数据。
3. `public/scripts/i18n.js`：保留 `t`、`translate`、`getCurrentLocale`、`addLocaleData`、`applyLocale` 的调用入口。翻译实现集中到共享模块；保留非 Nora 的旧语言设置初始化。
4. `extensions.js`：插件词典按准确语言代码、合法别名/基础语言查找，`en-US` 可以使用酒馆助手已有 `en` 词典；中文不误用英文词典。
5. `dom.js`：只处理明确标记的原生系统模板及其属性，不扫描/替换聊天内容，不启动全页翻译观察器。
6. `nora-entry.js`：从上游现有 `public/locales/zh-cn.json` 打包 ST 中文词典。兼容前置模块可能先执行，所以在词典注册后、展示 Nora 前再处理原生模板，保证弹窗默认按钮取得正确译文。
7. `src/nora-locale-bootstrap.js` 与 `public/index.html`：从同一份词表生成首屏小词表；加载遮罩、重试和静态布局在引擎可用前按同一语言显示。
8. 思考显示只翻译状态、耗时和复制提示。原生节点复用、折叠状态、流式思考正文和回复正文处理不变。

`public/`、`src/` 相对于 `app/engine/sillytavern/`；Nora 控制器位于 `app/native-extensions/nora-ui/`。

## 明确保留的内容

- 用户/模型消息、真实思考正文、角色卡正文、世界与角色已有名称、世界书内容、供应商和模型 ID。
- MVU 协议值 `自定义` 和中文变量属性键；源代码检查发现该值用于比较，已保留，且以中英环境测试独立模型选择不变。
- 主理人复盘草稿、尚未保存的默认配置名称及用户保存的配置内容，不把它们作为普通 UI 标签自动改写。
- 开发诊断、外部模型返回的原始错误、卡作者自定义界面和第三方自己写死的内容，不声称全部已翻译。
- 没有修改发送、停止、导入、保存、删除等业务接口，也没有新增后台服务。

## 资源成本

相同 Brotli 默认压缩设置比较：旧入口 36,978 字节，新入口 116,407 字节；原 inline 模块包 509,348 字节，新包 518,664 字节。新增首屏内联语言代码压缩后 800 字节。这三项合计增加约 87.4 KiB，不含原有延迟面板 chunk 的变化。
