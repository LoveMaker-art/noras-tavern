# Nora MCP 0.3：现有插件运行控制

日期：2026-08-30。范围：本地源码与针对性技术验证。没有部署远端、修改若棠/宿主 MCP 配置、操作真实会话、调用付费模型或修改界面布局。

## 用户目标与验收口径

若棠能够明确选择 Tavern 页面和世界，查询或控制当前已经接入的插件/脚本；操作结果来自真实运行接口，而不是修改 JSON 后猜测成功。

- 保留：ST、Helper、MVU、剧情账本和 Story Profile 的现有业务逻辑及 UI。
- 增加：固定控制目录、认证命令投递、实际页面执行器、持久回执、Helper 原生状态适配。
- 不做：任意 JS/shell 执行、第三方插件安装、恢复已移除 UI、为政策禁用插件强制解除限制、任意变量裸写。
- 不声称：所有第三方脚本无副作用、任意插件自定义功能自动获得控制接口、未打开网页也能运行浏览器插件、真实复杂卡全部验收通过。

## 控制链路

`若棠 → nora-mcp → 已认证 Tavern /api/nora-controls → 指定页面的执行器 → 现有插件接口 → 操作回执`

现有后端能力仍直接调用 World Core、账本、Story Profile，未转发到浏览器，也未另写一套生成算法。

MCP 注册数：read-only 30；operator 45（15 个写工具）。其中控制目录列出 37 个运行动作：11 读、26 写，通过统一 read/execute 工具使用。

## 对象清单与行为

| 对象 | 本次运行控制 | 实际接入点 / 限制 |
| --- | --- | --- |
| MVU | 状态、最近消息变量读取、全局参数、额外模型解析开关、模型来源、重试、托管运行时开关 | 已有 Mvu API / ST MVU adapter；独立模型密钥仍走后端。全局设置可能被角色卡覆盖 |
| Helper 脚本 | 全局/当前角色/预设查询、详情、新建、编辑、删除、开关、范围权限 | 原 getScriptTrees / replaceScriptTrees；新建默认关闭，带来源和版本检查，不替换其他脚本 |
| Helper 按钮 | 查询已启用脚本公开的按钮、按 ID 触发 | 原事件总线 emit(button_id)，不是猜测 DOM 或模拟点击；自定义异步任务只报告已触发 |
| Helper 设置 | 渲染、音频、宏等现有非敏感基础设置 | 原 reactive store + 原 schema；保留嵌套对象引用，显式 flush 原保存逻辑，不只改 ST 的序列化副本 |
| 正则 | 全局/角色/预设读取、创建、编辑、删除、开关、范围授权 | 原 regex engine；版本包含所属来源，拒绝过期修改；角色规则保存后读取后端确认 |
| 前端扩展 | 清单、开关、已有映射配置 | 原 enable/disableExtension；通常报告需刷新，不假装卸载已执行模块 |
| 当前世界 | 检查运行卡、修改开场白及叙述字段、发送、重生成、智能回复、停止 | 校验 World 运行卡归属；不改卡库源、不改已有聊天开场消息；调用现有 action dispatcher |
| 剧情账本 / Story Profile | 保留现有状态、配置、压缩、复盘、学习、刷新工具 | 复用既有后端服务，不重复实现 |

MVU 特别区分：

1. `mvu.enabled`：切换额外模型自动解析；关闭后回到随 AI 输出，不代表全部 MVU 停止。
2. `mvu.runtime`：持久保存 Nora 托管脚本启停策略；需要刷新。启动同步不再无视用户停用而重新开启。
3. 卡内嵌入 MVU：属于卡内脚本，通过对应 scripts.enabled 控制；托管开关不偷偷改写嵌入脚本。
4. `mvu.data` 只读；未初始化明确不可用，不生成伪变量。

保护项：Nora UI 外壳、托管 MVU 脚本身份、Helper/MVU 依赖、产品政策禁用的 assets、attachments、connection-manager、gallery、memory、token-counter。当前无 Quick Reply 前端模块、无已安装服务端插件；仅保留相应旧数据/清单读取，不假报可运行。

## 正确性和运行成本

- 页面、World、Session 必须精确匹配；世界已切换拒绝执行。不默认选第一个页面。
- 页面执行通过现有任务调度器登记；持久化期间现有切世界保护能看见这项任务。停止走原 visible 取消链路。
- 生成中、MVU 变量更新中拒绝新的管理写入。不是整个应用/所有浏览器的分布式锁；原后端离线编辑工具仍需避开在线修改。
- 共享的空白运行卡、外部/旧共享运行卡不允许直接改卡片、卡内脚本或卡内正则，避免一次管理修改影响多个世界。此处明确拒绝，没有暗中复制/迁移卡数据。
- Helper 范围权限沿用原生角色名/预设名；正则权限沿用头像/预设。它们不是新增的 World 独立权限，同名或共享资源可能共用授权；返回的 source 指明实际控制对象。
- 写操作要求 confirm；脚本与模型敏感动作有明确授权字段。这不是对恶意插件的沙箱。
- 服务端投递前持久标记 running；同键不重复投递。超时、断连、重启后的未知结果不自动重放。
- 队列最多32项；后台每页面一个20秒长轮询，30秒请求超时，断连延迟重连。启动主链路不等待控制连接，不自动开世界或刷新。
- 回执摘要单文件原子写，按哈希分片；终态不长期占用内存。不设置“执行2000次后永久停止”的管理次数上限。
- 回执不含脚本正文、聊天、密钥；结果只保留最近64份、单份最多512k字符。摘要会累积，维护不得直接删除仍可能被重试的操作幂等记录。
- 原生脚本停用不保证撤销已发出的网络请求、定时任务或外部副作用；需要重载/未知状态均原样报告。

## 实现位置

- Tavern `public/scripts/nora-controls/{contract,runtime,client}.js`：目录、执行器、页面连接。
- Tavern `src/{nora-control-broker.js,endpoints/nora-controls.js}`：认证路由、投递及回执。
- Tavern `public/scripts/nora-runtime/index.js`：非阻塞启动连接。
- Tavern `public/script.js` / `st-context.js`：增加严格保存入口，不改变旧调用方默认行为。
- `app/native-extensions/JS-Slash-Runner/nora-control-adapter.js`：原响应式状态与持久化的窄接口；绑定在托管 bundle 的可读前缀，上游升级必须核对符号。
- `app/native-extensions/nora-mvu/{runtime,index}.js`：持久停用策略。
- 同级 `nora-mcp`：五个控制工具、只读权限、错误语义、版本0.3、说明和集成测试。

## 本轮验证及剩余边界

已通过：

- Tavern 针对控制、MVU、已有适配、Story Core、Helper 调度和展示边界的82项测试。
- MCP 编译及11项测试，包括真实 stdio 的30/45工具权限发现。
- 跨项目隔离集成：真实 stdio MCP、HTTP路由、长轮询客户端、执行器及原任务调度器；MVU模式修改获得回执，同幂等键不重做，只读入口拒绝写动作。
- Story Core 静态契约和相关文件语法检查。
- 前端构建与运行资源生成；基础库体积警告仍存在，不是本轮新增另一套基础库。

未达到的证据层级：

- 不控制浏览器，因此未用真实页面/复杂卡逐项验收37个动作；Helper 原状态适配和代码绑定已检查，真实iframe脚本生命周期仍需目标环境验收。
- 未触发真实模型生成、MVU重试或收费脚本；集成测试中的页面上下文、MVU对象是夹具，不把它写成真实模型验证。
- UI shell 契约检查因本地缺少 cheerio 未运行成功；本地也没有 ESLint 可执行文件。没有为此额外安装或改动依赖。
- 未部署/重启本地或远端服务，未修改若棠配置和技能，未提交Git。nora-mcp当前仍是同级独立目录而非Tavern受跟踪子目录，部署/归档必须同时包含它，不能只提交Tavern后声称MCP已交付。

结论：本地控制代码和上述技术验证已经落地；目标机器的真实页面与若棠操作验收尚未完成。部署必须同步升级后端、页面资源、托管Helper和MCP，不能仅更新MCP包。
