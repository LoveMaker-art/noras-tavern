## 本轮已实现

- 期望安装清单包含“不变的文件”，不再把第二次更新中未变化的 AGENTS 当成退役文件。
  独立技能安装器仍默认只返回差异，重复安装仍为 no-op。
- AGENTS.md / config.yaml 不允许通过“未列入下一清单”这一条件隐式删除。
- 引擎 schema 2 与用户数据版本分开检查。混合 Python 状态、残留 World v1 注册表、
  不支持或损坏的 World JSON 会阻止 review/apply，且 apply 前重新检查。
  v1 注册表可能是已迁移后的历史副本；拦截表示需要核对，不代表数据一定损坏。
- apply 在 npm 准备前及停服前检查空间。初次预留 managed 文件备份/替换大小加
  1 GiB 依赖预算；停服前再次预留 managed 文件大小加 64 MiB 余量。
  npm 体积仍属估算，不保证中途磁盘永远够用，也不等于完整用户数据备份。
