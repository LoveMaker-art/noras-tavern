# 启动器安装位置

首次安装沿用默认目录。点击文件夹图标才打开系统目录选择窗口；取消不改变位置，点击“安装酒馆”直接开始安装。

## 目录边界

- 选择父目录后创建专属子目录；正式版为 `NoraTavern`，Beta 和候选包保留各自的隔离名称。
- Hermes、酒馆、安装记录和下载缓存统一读取选定的根目录，不引入第二套安装或更新实现。
- 无归属记录的非空目录、符号链接根目录、启动器应用目录和其他测试通道的目录禁止使用。
- 已有 Hermes、酒馆或开始安装记录时，不再提供更改位置。本轮不做目录迁移。
- 已有安装仍由原有状态检查决定继续安装、配置模型或进入日常启动界面，归属记录本身不代表安装成功。

## 重新打开与卸载

默认隔离目录的 `installer/location.json` 只保存版本、通道、目标路径和归属标识，不保存 Key。重新打开读取它；外部磁盘不可用或归属变化时停止加载，不偷偷回到默认目录重装。

卸载继续调用已有流程，传入当前实际根目录。保留数据卸载和彻底卸载的删除范围都跟随此路径。彻底卸载后可保留默认目录内的位置偏好；下次启动在原位置建立新的空安装。首次切换位置前已创建的启动器窗口缓存可能留在默认隔离目录，不包含模型配置或 Hermes 数据。

## 验证范围

`ops/tests/launcher_location.test.cjs` 覆盖位置持久化、已有安装保护、通道隔离、路径限制、安装中锁定、外置磁盘离线及卸载后重装。单元测试不等同于三平台的系统目录选择窗口和真实安装验收。
