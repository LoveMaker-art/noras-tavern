# Tavern 2.0.0-rc.6 — 对齐旧版有效登录流程

本版为预发布测试版，包含 Tavern、Story Profile、Nora MCP、官方技能和更新器。
不合并 main，不替用户更新或重启远端机器。

## 相对 rc.5 的变更

- 恢复 Python v1.24.12 更新流程已有的 Liveware 登录准备：校验发布包之后、审查和停服之前，检查目标机器鉴权；只有明确执行 `--apply --confirm` 且鉴权失败时，调用目标机器原有 ClawChat 插件登录一次，然后重新验证。仅审查不登录。
- Liveware CLI 和 ClawChat 插件统一使用目标安装的 HOME / HERMES_HOME。优先读取目标机器 `.clawling/liveware.json` 的凭证、平台地址和实例，不依赖模型临时拼接 export 命令。凭证只传入子进程环境，不进入发布包、更新计划或回执。
- 区分鉴权失败、超时、不可用命令、错误返回格式和凭证文件损坏；鉴权准备失败明确报告“未停服、未切换活动文件”。不再只有笼统的 `Liveware command failed: app list`。
- 网络失败不尝试登录；绑定、注册、创建和整个更新事务都不自动重试。不更改既有 App ID，不增加第二个 Tavern。
- 保留 rc.5 的官方历史文件精确识别、用户定制保护、整目录切换、Python 数据迁移与失败回滚。不改酒馆 UI、聊天、模型逻辑或 Hermes 生命周期安全守卫。
- 发布包继续不携带用户模型配置或密钥，只使用目标机器自己的配置；保留精简后的资源。

## 测试命令

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/download/v2.0.0-rc.6/install-tavern-updater.sh | sh -s -- --tag v2.0.0-rc.6 --allow-candidate --apply --confirm
```

去掉 `--apply --confirm` 为只读审查。不要用 `releases/latest` 测试此预发布版。
安装成功后，在 ClawChat 与若棠的对话中发送 `/restart`，按提示重载 MCP 和技能。
更新器不自行重启 Hermes。

## 验证与限制

验证范围包括真实子进程凭证/登录协议夹具、Bootstrap 授权边界、官方 Python v1.24.12 安装迁移、
世界/聊天/故事档案内容保留、同版本重复更新和失败回滚。隔离数据为合成测试数据，不调用模型。
这些结果不等于在所有用户机器上的实际更新已经验收。

仍需目标用户验收 ClawChat 更新入口和重载后的界面。目标平台不可达或真实凭证无效时，
更新会安全停止，不承诺掩盖外部服务错误。
Hermes 对某些 shell 命令的独立生命周期守卫异常未在此项目中修改或绕过。
Liveware CLI 不能读取原 tunnel 上游；绑定修改后发生失败时，未知原绑定不能自动恢复，
需按 `integration-pending` 提示核对。
此前暂缓的 `image-size`、`showdown` 安全问题未在本次解决，本版不宣称满足稳定版标准。
