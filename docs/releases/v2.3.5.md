# 诺拉·酒馆 v2.3.5

## 本次更新

- 每个世界使用独立预设：在右侧“预设 → 编辑”调整提示词开关、顺序和生成参数，保存后仅作用于当前世界。
- 预设可以复用和删除：将当前配置另存到预设库，供其他世界选用；删除库内模板不会影响已经应用到世界中的独立副本。
- 新增“重新开局”：点击世界右侧的“…”选择重新开局，确认新名称后创建独立世界。沿用人物、世界背景、世界书、预设与外观，从设定中的开场重新开始；原世界和故事记录保留，不带入旧聊天、摘要和已变化的角色状态。
- 模型连接与生成参数分开管理：更换模型不再覆盖世界预设中的参数。新配置默认上下文上限为 30000、回复上限为 4000 tokens，已有明确设置不会统一覆盖；这些数值不代表所有模型都支持，请按所用模型能力调整。
- 修复 MVU 独立模型的额度使用：整理请求上下文时使用独立配置的上限，不再误用文本预设上限；跟随文本模型时使用当前世界的额度。未更改 MVU 变量解析与更新协议。
- 修复本机多实例的预设保存问题：不同数据目录使用独立会话 Cookie，避免不同端口的酒馆相互干扰；保留原有 CSRF 校验。

## 使用说明

- “开启新世界”仍用于空白创建或导入角色卡；“重新开局”用于沿用已有世界的设定重新体验。新旧世界的设定副本和故事记录分别保存。
- 更新后请刷新已经打开的酒馆页面，让新界面与会话配置生效。
- 系统不会批量替换用户已有预设的参数，也不会因本次更新主动清空世界和聊天记录。

## 验证范围

本轮功能已通过针对性的接口与逻辑测试，覆盖世界与预设隔离、创建重试去重、模板保存删除、本地会话隔离和 MVU 请求额度。发布流程另行校验更新组件、三平台环境复用与用户数据保护；这些检查不等同于所有设备、模型和角色卡的完整实测。
