# Tavern 2.0.1

本次重点：程序更新与旧 Python 数据导入分别判定，个别不兼容数据不再阻止新版安装。

- 普通备份文件原样归档，不计为导入失败。
- 正常卡、世界书和世界继续导入；不兼容记录保留原件并给出待转换清单。
- 世界缺少依赖或聊天无效时整体待转换，不留下半个世界；无效账本不替换有效原始聊天。
- 有效 Story Profile 保持原内容；不兼容文件原样归档，目标机器的模型配置保留并单独处理。
- 修复 Python 服务恢复后的 PID 变化导致的重试阻塞。未切换文件、源代码未变化且原服务健康的旧事务可安全结清。
- 已确认绑定与名称后，公网入口验证失败单独报告，不撤销健康的本地安装。
- 同步更新技能说明，区分安装、数据导入、公网访问和 Hermes 激活结果。

仍保留磁盘/备份失败、非法路径、未知进程、文件被修改和真正未完成目录切换的安全保护。
待转换 Python 数据不等于可以直接用角色卡导入按钮载入。没有新增 Node 旧格式迁移。

发布包统一包含 Tavern、Story Profile、Nora MCP、四个官方技能和 AGENTS 受管内容。
不附带开发者模型、密钥或用户数据；继续使用目标机器配置。不会新建重复 Liveware App。

更新命令：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/latest/download/install-tavern-updater.sh | sh -s -- --apply --confirm
```

原仓库 `LoveMaker-art/liveware-tavern` 的地址通过 GitHub 仓库重定向保持可用。
安装成功后，在 ClawChat 对话中发送 `/restart` 加载新 MCP 和技能。
发布本版本不会自动更新任何用户机器。

本地已验证更新事务、数据准备脚本、迁移结果和真实临时进程恢复；
不把本地自动检查当作所有用户数据或 Liveware 公网环境的验收。
