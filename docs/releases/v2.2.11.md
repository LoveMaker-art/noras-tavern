# 诺拉·酒馆 v2.2.11

## 下载

- Mac Apple 芯片：选择 `Nora-Tavern-Launcher-0.3.2-mac-arm64.dmg`。
- Mac Intel：选择 `Nora-Tavern-Launcher-0.3.2-mac-x64.dmg`。
- Windows 64 位：选择 `Nora-Tavern-Launcher-0.3.2-win-x64-setup.exe`。

首次打开后按界面完成安装、模型配置和 ClawChat 连接。整合包包含 Hermes、Python、Node.js、诺拉配置与技能、MCP、Liveware 和酒馆；模型服务及 ClawChat 连接仍需要联网。

## 安装与更新须知

- 本版进入正式更新通道。已有正式安装可在启动器中检查版本；测试版与正式版的数据目录隔离，不会自动迁移测试密钥、配对和会话。
- 关闭启动器窗口不等于停止服务；可在启动器中分别停止诺拉和酒馆。电脑休眠、关机或断网会影响使用。
- 安装包不含用户 Key。Key 在用户配置模型后保存到本机；调用模型时会发送给所选模型服务。
- macOS 包未经过 Apple 公证，Windows 包未进行发行商代码签名，系统可能提示安全警告。请只从本仓库下载并核对校验信息，不要关闭系统整体安全保护。
- Mac Apple 芯片版本已完成用户本地安装验收；三个平台发布前执行自动化安装与包内容检查，不代表所有系统版本均已真机验收。
