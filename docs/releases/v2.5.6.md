# 诺拉·酒馆 v2.5.6

本版本包含启动器 **2.2.6**，Hermes 保持官方 **v0.21.1**。

- 集中改进故事偏好复盘：按会话增量取材，输出额度跟随当前酒馆文本模型；提取、保存和口味总结分别核验，失败后可继续，避免重复学习或一次处理全部历史聊天。
- 精简写入 USER.md 的稳定偏好，并按剩余容量保护其他内容；默认 USER.md 容量调整为 2000 字符，保留用户的其他有效自定义设置。
- 故事年表直接展示有效剧情账本中的进展与线索，支持多个世界和分支折叠；不再混入偏好学习流水记录，也不另调模型生成一份年表总结。
- 诺拉按明确世界和分支读取剧情账本，必要时有界补读近期聊天；剧情不再常驻 MEMORY.md，已有聊天、偏好、档案及其他记忆继续保留。
- 修复故事分支名称保存，以及世界创建和资料库操作中的相关数据保护问题。
- 修复模型验证连续失败后配置表单可能被长期拦截的问题，保留原始调用失败原因，允许在短暂限速后重新提交。

自动整理故事偏好在尚无设置记录时默认开启；已有关闭选择继续有效。达到条件时会使用当前酒馆文本模型，可能产生额外调用费用，可在“角色与设定 → 故事主理人 → 偏好设置”关闭。剧情账本和 MVU 的选择保持独立。

更新继续保留聊天、角色、世界、模型配置和原有档案。已有未完成恢复的安装请保留数据、日志和备份，不要手工删除更新记录或用户数据。
