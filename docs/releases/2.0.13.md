# Tavern 2.0.13

本次重点：修复 Liveware 环境中关键启动资源无法命中静态缓存，以及插件变化导致全部核心资源缓存失效的问题。

- 将约 2.45 MB 的关键启动清单从 `inline-modules.json` 改为内容不变的 `inline-modules.js`，使 Liveware 能按静态文件规则缓存并复用 Brotli 响应。
- 核心资源和第三方扩展使用独立的内容哈希地址；插件变化不再让整套核心 JS、CSS 和图标重新冷下载。
- 首页继续使用不可缓存响应，资源内容变化时自动生成新哈希 URL，因此长期静态缓存不会固定旧版本。
- `/version` 现在同时公开页面、核心资源和扩展资源版本，便于定位实际缓存命中情况。
- 更新架构文档和项目索引，并加入缓存命名空间及发布内容回归测试。

更新命令：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/latest/download/install-tavern-updater.sh | sh -s -- --apply --confirm
```

安装完成后，在 ClawChat 对话中发送 `/restart`，重新加载 MCP、技能和 AGENTS。
