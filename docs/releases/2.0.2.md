# Tavern 2.0.2

本次重点：让旧版 MVU 角色卡在 Nora Tavern 中能够被正确识别、导入并持续更新变量。

- 统一新版与旧版 MVU 能力识别，兼容旧 `TavernHelper_scripts`、`[InitVar]`、`<UpdateVariable>`、`<JSONPatch>` 与 `_.set()` 更新规则。
- 导入旧卡时只生成兼容的内部 Runtime Card，不修改用户保存的原始角色卡。
- 只有原生支持 `[mvu_update]` / `[mvu_plot]` 分离协议的角色卡才把更新规则交给独立变量模型；旧卡继续由正文模型执行更新，避免两条链路都拿不到规则。
- MVU 状态不再只依据运行时加载或初始化。变量实际变化后才显示“更新正常”，无命令或状态未变化会明确显示“更新未生效”。
- 不同世界的 MVU 更新观测相互隔离，避免切换世界后沿用旧状态。
- 重新生成生产前端构建产物，并补充旧卡导入、提示词路由、Runtime Card 投影和真实更新观测测试。

更新命令：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/latest/download/install-tavern-updater.sh | sh -s -- --apply --confirm
```

安装成功后，在 ClawChat 对话中发送 `/restart` 加载新 MCP 和技能。
本版本不会附带开发者模型、密钥或用户数据，也不会自动更新任何用户机器。
