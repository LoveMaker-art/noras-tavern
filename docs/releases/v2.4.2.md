# 诺拉·酒馆 v2.4.2

本次发布包含启动器 **2.0.2**，集中修复 Windows 更新、更新中断后的恢复，以及故障诊断不完整的问题。

- 修复 Windows 的本地依赖目录链接在更新时引发目录移动失败、拒绝访问或依赖失效的已知问题。新安装和复用的依赖都会在替换程序目录前完成检查和准备。
- 修复 Windows 传统路径长度限制下，深层插件缓存导致更新备份校验失败的问题；备份、完整性校验和恢复均支持长路径。
- 更新中断后，启动器会检查事务记录和旧版本备份。符合恢复条件时显示“恢复旧版本”，保留失败现场后恢复旧程序、配置和原有服务状态；记录不完整或备份无法核实时保留现场，并提供日志说明。
- 恢复页使用一个清晰的主操作，错误详情和备份位置默认折叠；恢复条件变化后，按钮和说明同步刷新，恢复进行中不会被状态刷新打断。
- 补齐安装、更新和日常启动失败的详细诊断，保留限定的项目调用位置、错误原因链、Node 程序错误码及恢复失败的次要错误；诊断被裁剪时明确标记，便于定位问题。
- 改善网络连接重置和 Node 启动后立即退出时的中文提示。外部服务或网络仍可能失败，启动器会保留相应错误信息。
- 清理重复异常处理、不可达回滚分支和正式包中的历史预览页面，统一受管事务的状态判断与记录保存。

详细诊断遵循首页“自动发送详细故障诊断”开关，已有关闭选择保留。不收集聊天内容、模型回复、密钥或 Hermes 日常内部日志；基础操作阶段、耗时和运行状态继续自动上报。

提供 Windows x64、Mac Apple 芯片和 Mac Intel 的完整安装包，以及已有安装使用的轻量启动器更新包和组件更新。已有安装通过启动器执行更新，保留聊天、世界、模型配置和密钥。恢复按钮只用于具备完整恢复计划的未完成更新，无法自动补齐旧版已经丢失的记录。
