# 诺拉·酒馆 v2.3.2

## 本次更新

- 启动器升级至 0.3.4。本地已安装内容改用与云端相同的更新器，不再重新执行首次安装流程。
- 更新前核对现有目录、端口和实例绑定；不移动数据，路径冲突时停止更新。
- 更新后检查世界、聊天记录、Hermes 与 MCP；失败时恢复原程序、配置和数据，并尝试恢复更新前的运行状态。
- 保留密钥、配对、会话及用户自定义人格，同时更新项目技能、开场白、Hook、脚本和定时任务。
- Windows 更新文件操作沿用长路径兼容处理，不要求用户修改注册表。

## 已有用户如何更新

**本次需要更换一次启动器。** 下载对应平台的 0.3.4 安装包，退出旧启动器后安装新版。保留原安装目录和数据，不要执行“卸载诺拉·酒馆”或清理 Hermes。新版会识别原安装，再从“更多 → 查看版本”更新内容。

之后普通酒馆、技能等内容更新仍从启动器中完成，不必每次重新下载安装包。只有启动器或运行环境本身变化时，才需要相应的平台包。

独立部署继续使用[更新指南](https://github.com/LoveMaker-art/noras-tavern/blob/v2.3.2/docs/update-nora-tavern.md)中的原更新入口。无需将云端目录改成本地安装目录。

发布流程要求 Mac Apple 芯片、Mac Intel、Windows x64 全部通过安装与已安装实例更新检查后才公开发布。Windows 同时关闭长路径支持进行测试。

本地已完成两轮从旧正式包到新更新器的真实演练，核对世界、聊天记录和用户配置，以及实际 Hermes 加载与 MCP 读取。自动验收不使用个人 API Key 或配对码，不代表每个 IM 平台上的真人对话都已重新测试。
