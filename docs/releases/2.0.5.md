# Tavern 2.0.5

本次重点：修复更新器在 Tavern 正常保存设置时可能误判文件缺失、从而中止更新的问题。

- 容量复核不再把原子写入过程中已经完成重命名的 `settings.json.<临时编号>` 当成数据损坏。
- 停服后的正式文件清单、指纹、备份与切换校验仍保持严格，不降低更新事务的完整性要求。
- 更新项目中英文说明，明确升级、迁移、Hermes 重载与失败恢复边界。

更新命令：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/latest/download/install-tavern-updater.sh | sh -s -- --apply --confirm
```

安装成功后，在 ClawChat 对话中发送 `/restart` 重新加载 MCP、技能和 AGENTS。
本版本不会附带开发者模型、密钥或用户数据，也不会自动更新任何用户机器。
