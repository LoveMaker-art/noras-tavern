# Tavern 2.0.6

本次重点：恢复简单、稳定的日常更新边界，不再让用户数据和 Liveware 平台状态阻塞已有 2.x 安装更新。

- 旧 Python 1.x 安装首次升级到 2.x 时，仍使用完整数据副本完成迁移、验证、切换和故障恢复。
- 已使用 Node 2.x 的安装只更新 Tavern、Story Profile、Nora MCP、官方技能、AGENTS 受管内容和官方扩展代码。
- 2.x 日常更新不再扫描、解析、复制、迁移或切换 Worlds、聊天、模型配置和 Story Profile 用户数据。
- 损坏或旧格式的 World 记录、临时 `settings.json.*` 文件以及更新期间新增的聊天，不再阻止代码更新。
- 2.x 日常更新不查询、注销、重新注册或重新绑定现有 Liveware App；Tavern 与 Story Profile 的既有 App ID 和入口保持不变。
- 代码更新失败时只恢复受管代码，用户在此期间产生的新聊天不会被回滚。
- 增加“完成针对性测试后快速打包”的维护通道，打包、校验和、版本清单与正式发布资产格式保持一致。

更新命令：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/latest/download/install-tavern-updater.sh | sh -s -- --apply --confirm
```

安装成功后，在 ClawChat 对话中发送 `/restart`，重新加载 MCP、技能和 AGENTS。更新器不会携带开发者模型、密钥或用户数据，也不会自动更新任何用户机器。
