# Nora Tavern v2.2.10

## 修复

- Liveware 注册与诺拉开场白独立进行，不再因开场白的完成标记未写入而一直等待。
- 酒馆入口在注册和地址校验通过后发送，允许先于开场白出现。
- 安装和更新时撤销已知的旧版 ClawChat 顺序补丁，恢复原有的开场白处理逻辑；不兼容的插件源码保持不动并报告待处理。

## 保留的安全检查

- 仍校验当前账户、实例归属、会话和入口地址。
- 保留注册锁、重试、消息确认及更新备份回滚机制。
- 不修改用户的模型配置、密钥、角色卡和聊天记录。

## 更新说明

本次为酒馆主线更新包，不包含新的桌面整合启动器。通过现有更新流程安装；涉及 ClawChat 插件文件替换后，需要重启 Nora 网关使其生效。

本次验证包括针对性的自动化回归和发布包校验，尚未进行真实云端首次激活到入口打开的端到端验收。
