# 诺拉·酒馆 v2.3.14

## 本次更新

- 启动器升级至 1.1.1，重新构建 Windows x64、Mac Apple 芯片和 Mac Intel 安装包。
- 修复覆盖安装新启动器后，旧酒馆没有继续升级的问题：识别包内版本，通过共享更新器完成升级，保留世界、聊天和配置。
- 修复旧安装的修复入口误将旧版本作为更新目标，导致发布清单校验失败的问题。
- 获取发布资源时遇到短暂的网络变化，最多自动重试两次；支持取消，不绕过证书验证，也不重跑安装事务。
- 更新日志增加当前版本、请求目标、最终目标和网络重试次数。
- 补充历史安装记录、升级目标选择及失败回滚检查；缺少系统安装记录的旧部署会提前停止，避免进入无法确认恢复方式的旧更新路径。

## 验证与边界

- Windows 用户测试日志已确认此前测试包完成 2.3.2 至 2.3.13 的更新，世界校验与酒馆启动成功。
- 本版补丁通过有限重试、取消、证书错误及更新回归测试；正式发布须通过三平台原生构建、安装更新和归档校验。
- 不承诺所有历史自定义部署均可自动迁移；未完成的恢复需保留日志和备份，勿清空数据重装。
