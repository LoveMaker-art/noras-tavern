# 诺拉·酒馆 v2.4.1

本次发布包含启动器 **2.0.1**，修复启动、更新和详细故障诊断中的已知问题。

- 修复 Windows 更新安装依赖时，长路径前缀导致 npm 报出 `Invalid file: URL` 的问题。
- 对安装身份和版本记录一致的旧部署，支持安全恢复缺失的系统安装记录，再执行更新；身份无法确认时仍保留现有安装和数据。
- 修复 Hermes 自身重启后，启动器丢失进程归属、误报未运行或阻止再次启动的问题。无法确认身份的进程不会被强行结束。
- 补齐启动、停止及配置操作的脱敏错误诊断：保留项目调用栈、错误原因链和停止多个服务时的次要错误，避免只收到概括性的失败提示。
- 详细故障诊断继续遵循首页开关选择，不收集聊天内容、模型回复、密钥或 Hermes 日常日志；基础操作阶段、耗时和运行状态继续自动上报。

提供 Windows x64、Mac Apple 芯片和 Mac Intel 的完整安装包，以及已有安装使用的组件和启动器更新包。已有安装通过启动器执行更新，保留聊天、世界、模型配置和密钥。
