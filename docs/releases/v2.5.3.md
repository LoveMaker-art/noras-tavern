# 诺拉·酒馆 v2.5.3

本版本包含启动器 **2.2.3**，Hermes 保持官方 **v0.21.1**。

- 诺拉与启动器按钮共用独立核心更新器，核心更新不要求安装或打开启动器；任务接管后调用方断开仍继续执行。
- 启动器发现酒馆和启动器都有更新时，一次点击依次完成；确认兼容时保留已成功部分，重试只处理失败部分。
- 区分酒馆核心与启动器版本；仅启动器变化不再触发诺拉的核心更新提醒。
- 修复 ClawChat 配对连续失败后的重试锁定，保留有限冷却并允许后续合法提交。
- 修复 Mac 启动器恢复、相关进程归属判断及历史更新事务恢复核验，保留用户聊天、角色、世界和配置。
- 核心更新计划先完成核验；可选启动器查询超时或失败时保留有效核心更新能力，并减少相同清单的重复读取。
- 完善组件发布、制品身份与国内分发校验；极狐继续作为国内主源。

历史版本说明：旧程序尚未取得新版更新器时，不承诺其所有原更新入口均可直接升级。遇到旧版事务或归属校验阻断时，请保留数据和日志，使用与该问题匹配的支持流程，不删除数据目录或恢复记录。独立 Windows 历史修复工具不包含在本次发行中。
