# Tavern 2.2.2

本版本修复长聊天只能看到最近约 40 条消息、用户容易误以为历史记录丢失的问题。

- 打开世界仍只渲染最近 40 条消息，保留手机端首屏性能。
- 向上滚动接近聊天顶部时，自动加载更早的 40 条消息，直至第一条。
- 顶部保留可点击的历史加载入口，并显示剩余消息数量。
- 历史加载失败时显示明确提示，可直接重试；不会修改或截断服务端聊天文件。

更新命令：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/latest/download/install-tavern-updater.sh | sh -s -- --apply --confirm
```
