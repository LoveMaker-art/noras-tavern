# Tavern 2.0.11

本次重点：修复更新后 ClawChat / Liveware 仍复用旧版 Tavern 前端的问题，同时保留内容寻址静态缓存的启动速度。

- Tavern 与 Story Profile 的 HTML 入口统一使用 `Cache-Control: no-store`，不再长期复用旧入口文档。
- JS、CSS、图片及运行时模块继续使用内容哈希路径和长期不可变缓存，未关闭有效的静态资源缓存。
- bootstrap 返回当前静态资源指纹；旧入口连接到新后端时只刷新一次，不允许旧前端继续运行。
- 资源指纹校验复用现有 bootstrap 请求，模块清单和静态资源仍保持并行加载，不增加新的启动网络波次。
- 更新器在新版 Tavern 启动后读取实际资源指纹，并刷新既有 Tavern、Story Profile 启动地址。
- Liveware 更新继续复用原 App ID；历史重复启动器记录会归一化，不创建新的 Tavern App。

更新命令：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/latest/download/install-tavern-updater.sh | sh -s -- --apply --confirm
```

安装完成后，在 ClawChat 对话中发送 `/restart`，重新加载 MCP、技能和 AGENTS。
