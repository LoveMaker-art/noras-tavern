# 诺拉·酒馆 v2.3.4

## 本次更新

- 库更好找：世界卡、角色、世界书分类展示，角色再分“我的角色”和“其他角色”。
- 设定可以复用：把角色或世界书单独保存到库，在其他世界的设定编辑中直接选用，也可以让诺拉帮你保存和使用。
- 相同完整卡不再反复堆积：创建世界时检查入库，内容相同复用已有卡，内容不同仍分别保留；每个世界的聊天和运行数据继续独立。
- 页面切换更连贯：减少库分类和同类弹窗切换时的闪烁，避免旧请求覆盖刚打开的内容。
- 阅读空间更自由：电脑端支持收起左侧世界栏，并记住本机选择；也可以让诺拉统一设置各世界默认的背景、文字颜色和字体，无需逐个调整。
- 诺拉管理设定更完整：可以按需添加、修改和删除独立角色，添加常驻或触发设定，并把库中资料应用到指定世界。

## 使用说明

- 全局外观直接告诉诺拉修改，不新增用户设置面板。单个世界已有的专属设置优先保留；其他已经打开的页面刷新后读取新配置。卡片内置 HTML 和独立 iframe 样式不在此次全局主题修改范围内。
- 保存到库和应用到世界是两个动作。单独保存的角色资料不等同完整卡，不附带开场白、头像、脚本、正则或 MVU 状态；完整卡仍可按原流程使用。
- 重复入库检查不按名字简单删除，也不清理被已有世界引用的运行卡。此次不更改 MVU 输出协议。

## 下载

完整安装包沿用 v2.3.3 的启动器 1.0.0；本次发布酒馆系统 2.3.4 更新组件。

## 如何更新

已有启动器用户在“更多 → 查看版本”检查更新，无需卸载或重新下载安装包。独立部署使用[现有更新入口](https://github.com/LoveMaker-art/noras-tavern/blob/v2.3.4/docs/update-nora-tavern.md)。

## 验证范围

本次沿用系统组件发布流程，校验更新包、三平台环境复用和世界数据保护。相关功能已有接口和逻辑测试；这些检查不等同于所有设备和角色卡的视觉验收。
