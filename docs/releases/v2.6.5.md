# 诺拉·酒馆 v2.6.5

本次包含诺拉酒馆核心 **2.6.5** 和启动器 **2.2.9**，重点修复安装、更新及故障恢复。

- 启动器分别显示自身与酒馆的更新状态。启动器更新只替换自身程序，酒馆核心更新继续从诺拉对话发起。
- 修复 Windows 首装遇到临时文件占用时提前失败的问题。确认回退且原安装资源完整时，可以从原页面重试。
- 修复启动器更新中断后恢复任务无法结束、重开后卡在原任务的问题。支持恢复旧启动器后继续使用。
- 改善启动、退出和保留数据重装。升级和保留数据重装会保护已保存的配置、世界和会话。

如果已安装的旧版诺拉技能仍要求通过启动器更新酒馆，请按[旧版核心接入说明](https://github.com/LoveMaker-art/noras-tavern/blob/main/docs/update-standalone-tavern.md#旧技能要求启动器时的一次接入)更新原安装目录。
