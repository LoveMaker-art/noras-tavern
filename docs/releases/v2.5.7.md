# 诺拉·酒馆 v2.5.7

本版本包含启动器 **2.2.7**，Hermes 保持官方 **v0.21.1**。

- 诺拉在桌面安装中可以按一次明确授权，交给启动器完成适用的酒馆和启动器更新；仅询问版本时在后台检查，不打开启动器。
- 修复先更新酒馆、再更新仍打开的启动器时，旧版本绑定导致交接失败的问题。
- 启动器版本查询失败时，已经确认资源有效且兼容的酒馆更新仍可继续；酒馆与启动器分别报告结果，不把部分完成说成全部成功。
- 补齐 Windows 完整运行环境中的 Git Bash，让固定 Hermes 版本能够执行授权的维护命令；不安装系统 Git，不改变 SSH、Tailscale 或代理设置。
- 精简运行环境安装进程的结果消息，避免完整文件校验清单过大导致安装读取失败；原文件校验与恢复记录继续保留。
- 完善更新中断、失败恢复和重试时的结果读取及配置保护；已完成的兼容部分保留，重试只补失败项。

聊天、角色、世界、模型配置、偏好和历史档案继续保留。桌面旧版不支持统一更新请求或缺少运行依赖时，不能仅凭新版技能宣称已经获得整套更新能力；应先通过适用的正式更新或保留数据安装路径升级。

本版本不包含历史修复工具的新版交付。已有恢复未完成的安装仍需按对应故障处理，不要手工删除更新记录或用户数据。
