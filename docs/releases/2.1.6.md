# Tavern 2.1.6

本版本改善首次加载与更新后的缓存体验，并加强角色卡导入恢复。

- 首页直接显示 Tavern 核心资源的加载进度，长时间加载时继续反馈当前状态。
- 将 ST 静态资源、Nora 界面、运行入口、兼容层和公共依赖拆为独立内容哈希；只重新下载实际变化的资源组。
- 为每个扩展生成独立内容哈希，并将 MVU 运行代码与稳定第三方库分开缓存。
- 首页使用 `no-store`，带哈希资源使用不可变长期缓存，避免更新后继续加载旧入口。
- 接受 `extensions` 为空的常见 V2 角色卡，并正确清理已经终止的导入记录。
- 导入中断后的恢复状态持久化，重启后不会长期残留“上次导入未完成”。
- 稳定 ColorOS 等嵌入式浏览器中的可视区域计算，减少界面高度和点击区域异常。

更新命令：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/latest/download/install-tavern-updater.sh | sh -s -- --apply --confirm
```
