# Tavern 2.1.7

本版本改善每日 Tavern 更新提醒的内容。

- 发现新版本时同时显示当前版本、最新版本和 GitHub Release 更新摘要。
- 自动过滤发布标题、代码块和安装命令，摘要最多保留 10 行、1200 个字符。
- 移除“用户数据尚未发生变化”提示。
- 没有新版本或同一版本已经提醒过时保持静默；检查失败仍只记录本机日志。
- 定时任务继续只负责提醒，不会自动安装更新。

更新命令：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/latest/download/install-tavern-updater.sh | sh -s -- --apply --confirm
```
