# 诺拉·酒馆 v2.4.0

本次完整发布包含启动器 **2.0.0**，提供 Windows x64、Mac Apple 芯片和 Mac Intel 安装包，以及已有安装使用的组件和启动器更新包。

## 启动器

- 首次安装检查最新正式发布，固定同一目标版本并校验资源；无法查询时明确询问是否使用包内版本。
- 统一更新酒馆与启动器，需要时先替换启动器再继续同一版本的组件更新，保留文件校验、备份及失败恢复机制。
- 安装和更新展示当前步骤、阶段耗时与总耗时。下载展示实际字节进度；连续三分钟没有新增下载数据时提示检查网络和代理，本地解压与校验不误报为网络问题。
- 将启动器操作失败转换为中文问题说明及处理建议，保留日志与重试入口。
- 修复 Gateway 状态记录、进程身份识别、Node 运行路径及 Windows 解压兼容问题；无法确认进程身份时不强行结束进程。
- 调整模型重新配置与运行时路由同步，改善重复配置后的状态反馈。
- 自动上报基础操作阶段、耗时和运行状态。首页提供紧凑的详细故障诊断开关，新诊断选择默认开启，已有主动关闭的选择保留。仅发送脱敏程序错误，不收集聊天内容、模型回复或密钥。

## 酒馆与诺拉

- 整合酒馆内核与扩展兼容改进，优化角色卡、预设提示词编辑和插件管理。
- 优化世界、会话与备份的存储操作；聊天备份支持预览、恢复和清理，并提供对应的 Nora MCP 操作。
- 优化账本任务的取消、会话切换和运行状态，整合紧凑设置入口。
- 完善 Nora MCP 与酒馆功能的对应关系及操作指引。

## 安装与更新

新用户选择对应系统的完整安装包；已有安装在启动器中查看版本并选择安装更新。启动器版本与酒馆版本独立编号，本次分别为 **2.0.0** 与 **2.4.0**。更新会保留用户的聊天、世界、模型配置和密钥。

未签名或未公证的平台安装包可能出现系统安全提示。
