# Tavern 2.0.0-rc.4 — 精简资源测试版

本版为预发布测试版，不合并 main，不替用户更新远端机器。
包含 Tavern、Story Profile、Nora MCP、官方技能和更新器。

## 相对 rc.3 的变更

- 安装包不再携带 ST 默认背景、Seraphina 示例角色及表情、配套 Eldoria 示例世界书。
- 安装包不再携带 Noto Sans / Noto Sans Mono 正文字体；Nora 默认界面原本即使用系统字体，正文样式不变。
- 保留 Font Awesome 按钮图标字体，防止内置功能及插件的图标显示方框。
- 同步清理默认内容索引、默认角色标签及透明背景图片引用；构建时阻止缺失资源进入默认索引。
- 不删除目标机器已有的背景、角色卡、世界或对话。不改变 token 计算，保留分词词表。
- 打包规则集中在发布模块；上游参考素材仍保留在源码中，但不进入运行时安装包。

精简验证包由约 44.21 MiB 降至 20.77 MiB，减少约 53%。
发布包不包含用户模型配置或密钥，继续使用目标机器自己的配置。

## 固定版本更新命令

在目标机器执行：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/download/v2.0.0-rc.4/install-tavern-updater.sh | sh -s -- --tag v2.0.0-rc.4 --allow-candidate --apply --confirm
```

仅审查可移除 `--apply --confirm`。不要使用 `releases/latest` 来测试此预发布版。
成功安装后，在 ClawChat 与若棠的对话中发送 `/restart`，按输出完成 MCP 和技能重载。
更新器不自动重启 Hermes。

## 验证与已知限制

本地精简包已通过构建、资源清单检查及隔离 Node 更新、健康检查和回滚验证。
这不等同于目标 Linux/ClawNest、所有第三方卡、ClawChat 界面与网关重载验收。
第三方卡若直接引用被移除的 Noto 字体文件路径，需要自带资源或使用系统字体。

rc.3 的限制继续存在：Liveware 尚不能读取 tunnel 原有本地上游地址；修改绑定后若后续失败，
本地可恢复，但未知的原绑定不能自动恢复。此时记录 `integration-pending` 并停止继续更新，
需要核对平台绑定。此前暂缓的 `image-size`、`showdown` 依赖安全问题未在本次解决。
本版仅供明确授权的预发布测试，不宣称达到稳定版发布标准。
