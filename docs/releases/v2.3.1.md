# 诺拉·酒馆 v2.3.1

## 本次更新

- 修复旧部署更新时可能选错安装目录、导致原世界看起来消失的问题。更新前核对原安装和 MCP 绑定；路径冲突时停止，不创建空实例覆盖原绑定。
- 为原生酒馆更新增加世界、会话和原文件校验；校验失败时恢复旧程序、配置与数据，不仅检查服务是否启动。
- 修正旧部署的版本检查目录识别。
- 将系统组件更新与完整启动器安装包构建分开。此次复用已验证的三平台运行环境，不重新构建 Hermes、Python、Node 或 DMG/EXE。

## 已有用户如何更新

- **启动器安装的完整版**：在“更多 → 查看版本”中检查并更新，无需重新安装启动器或清空数据。
- **Hermes 上的独立部署**：使用[更新指南](https://github.com/LoveMaker-art/noras-tavern/blob/v2.3.1/docs/update-nora-tavern.md)中的独立部署更新流程。不要将单体更新器用于启动器管理的完整系统。
- 如果此前已出现世界不见，请先确认原数据目录和绑定，不要删除原目录或反复重新安装。此次修复防止再次选错目录，不会擅自猜测并迁移已有错误实例。

## 验证说明

目录修复已在提供的 Linux 测试实例执行真实更新，并在服务重启后核对原世界、会话与 34 个受保护文件；随后按要求恢复旧版，供用户从正式发布再次验证。

本次运行三平台系统清单兼容测试与数据保留、失败回滚测试；复用环境不等于重新执行三平台原生安装验收。完整安装包仍为已发布的 v2.3.0，实际下载入口见上方。
