# 诺拉·酒馆 v2.5.0

本版本包含启动器 **2.2.0**。当前为本地主分支的未发布版本；最终三平台安装包和历史版本升级验收完成后才能正式发布。

- 国内版本查询和资源下载以极狐为主源，保留 GitHub 与 SourceForge 后备来源；下载始终绑定固定版本、文件大小和 SHA256。
- 下载支持按固定资源断点续传；持续慢源按实际进度和剩余预算切换，支持 Range 的后备源继续已有进度，源不支持续传或内容不符时重新下载。
- 缓存写入或状态显示失败保留实际维护结果；重开后按当前实例、版本、提交和实时服务状态核对，避免旧错误持续阻断。
- 已有安装缺少托管 Python 或酒馆程序时，在归属、版本和停止状态核验后补齐程序，保护聊天、世界、配置及备份。
- 更新前后的数据保护、备份容量和停止后的配置检查使用统一职责；恢复和重试保留原始失败、固定目标及现场证据。
- Windows 恢复采用较短的临时名称和索引备份布局，补齐目录及恢复路径操作的长路径适配，兼容读取旧备份记录。
- 保留数据卸载与重装核验原安装归属；彻底卸载在停服、锁和现场归属确认后清理，无法确认时保留现场并记录原因。
- 启动初始化失败和 GUI 退出后的卸载失败保存到持久诊断队列；网络失败留待重发，详细日志继续受用户授权控制。
- 安装、模型、配对、错误与恢复页面使用统一位置；表单标签、控件和按钮边缘对齐，去掉点击后的额外粉色焦点外框，小窗口内滚动保留完整控件。
- 统一测试执行环境和临时进程清理，构建前执行源码门禁；正式发布工具消费已验收的固定资产，再校验公开渠道和版本入口。
