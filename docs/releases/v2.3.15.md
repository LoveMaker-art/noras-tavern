# 诺拉·酒馆 v2.3.15

## 本次更新

- 启动器升级至 1.1.2。日常启动与首次安装验收分开：不再因用户修改技能或其他文件而自动重装、覆盖；显式安装和更新仍进行必要校验。
- 修复 MVU 独立模型的占位地址路由：兼容 OpenAI 代理路径和自定义接口路径，在供应商请求前解析实际配置；配置缺失时明确报错，避免请求无效域名。本项不改卡片协议、提示词或 Zod 规则。
- 增加本地整页明亮、黑暗、跟随系统接口，持久保存选择；世界配色独立保留。非本地 Liveware 页面跟随浏览器/WebView 的颜色偏好，不保证同步宿主应用手动选择的皮肤。
- 酒馆技能更新至 1.25.2，明确整页外观与世界配色的接口分工；缺少外观接口时报告限制，不将历史 CSS 或整份设置写入方案当作日常切换方法。
- 卡片内按钮或输入触发生成时，统一显示生成状态；整理增强能力扩展入口及正则查看、编辑交互。
- 制卡技能更新至 0.3.1，纳入已合并的字段校验、状态栏模板与制作流程改进。

## 验证与边界

- 本地 Hermes 原会话已通过整页三种模式的接口保存、应用和读回测试，并恢复原设置；该验证不替代视觉验收。
- 本版包含启动器、独立模型路由、主题和相关功能回归检查；完整发布由三平台构建、安装更新及归档校验共同把关。
- 发布包不包含本机用户会话、模型密钥、个人配置、清理备份或测试数据，也不会通过本次更新清理其他用户的自定义内容。
