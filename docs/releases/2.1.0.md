# Tavern 2.1.0

本次重点：收敛复杂角色卡、MVU、World 启动和 Agent 控制边界，并清理发布源码与重复运行时资源。

- 完善复杂角色卡导入与 ST Prompt Template 兼容，补齐 MVU、Tavern Helper 和脚本所需的核心模块桥接。
- MVU 额外模型完整继承文本模型配置，保留原版变量更新上下文与规则；请求超时上限调整为 120 秒，并补充可追踪的失败诊断。
- 合并同一 World 的重复激活请求，避免并发切换和恢复产生重复加载；应用外壳不再等待初始 World 恢复后才显示。
- 修复移动端软键盘弹出时输入框被遮挡，以及编辑后富文本/HTML 消息不能持续正确渲染的问题。
- 收敛 Nora MCP 为清晰的读取边界，移除旧的过大控制平面和已失效写接口。
- 补齐首次安装文档和 Nora + Tavern / 仅 Tavern 两套安装入口。
- 清理发布源码审计结果，并删除未被页面或运行时使用的第二份 `dist/nora/lib.js`；正式 `/lib.js` 保持不变。

更新命令：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/latest/download/install-tavern-updater.sh | sh -s -- --apply --confirm
```

安装完成后，在 ClawChat 对话中发送 `/restart`，重新加载 MCP、技能和 AGENTS。
