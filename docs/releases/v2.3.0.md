# 诺拉·酒馆 v2.3.0

## 本次更新

- 重写项目首页，讲清以世界为核心、Agent 可管理的开源 AI 角色扮演体验，并加入电脑端、手机端与 Story Profile 的产品截图。
- 整理安装、更新与卸载指南：三个平台直接下载；完整版与源码版分别说明；补齐 Git、Node.js 和终端操作步骤。
- 加入预设库与世界设置编辑保护，完善角色引用、角色独立设置、世界书条目编辑与启用状态的处理。
- 按职责整理酒馆源码、Nora 人格与技能、启动器、安装与更新模块。交付仍兼容现有安装目录，不要求用户手动搬迁文件。
- 三个平台使用同一份 v2.3.0 源码重新构建，桌面启动器版本为 0.3.3；保留诺拉图标、完整 Nora 配置及现有安装、模型同步和卸载流程。

## 已有用户如何更新

- **启动器安装的完整版**：在“更多 → 查看版本”中检查并安装更新。系统内容更新与桌面启动器替换的区别见[更新指南](https://github.com/LoveMaker-art/noras-tavern/blob/v2.3.0/docs/update-nora-tavern.md)。需要新版桌面程序时，下载对应平台安装包并替换，不必先彻底卸载或清空数据。
- **源码安装的精简版**：按[源码更新步骤](https://github.com/LoveMaker-art/noras-tavern/blob/v2.3.0/docs/install-tavern.md#更新源码版)备份数据、拉取代码并重新构建。存在本地代码修改时，先处理修改，不要强制覆盖。
- 正式版与测试版的数据目录隔离，不会自动迁移测试密钥、配对和会话。

## 安装须知

- 安装后仍需配置模型和连接支持的 IM 平台，具体操作见安装指南。本整合包当前使用 ClawChat 配对。
- 安装包不含用户 Key；配置后保存在本机，调用模型时发送给所选服务。模型服务可能另行收费。
- 关闭启动器窗口后服务继续运行；可分别停止诺拉与酒馆。电脑休眠、关机或断网会影响使用。
- macOS 包未经过 Apple 公证，Windows 包未进行发行商代码签名，系统可能提示安全警告。请从本仓库下载，不要关闭系统整体安全保护。
- 发布流程要求三个平台通过自动化安装及包内容检查；这不等同于所有系统版本均已真机验收。
