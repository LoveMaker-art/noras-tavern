# 诺拉·酒馆 v2.4.6

本次版本包含启动器 **2.1.3**。

- 修正 Windows 中文路径下首次准备运行环境时的技能文件复制。
- 已有安装缺少托管 Python 或酒馆程序时，可在核验安装归属、版本记录和停止状态后补齐程序，保留原有聊天、世界、配置和备份。
- 修正失败恢复、成功修复与后续更新之间的历史事务判断，保留恢复证据，避免已结束的旧操作持续阻断更新或卸载。
- 卸载检查按实际文件读取进度判断停滞，避免将正常的大目录校验误判为超时；未完成或无法确认的事务仍保留现场。
- 完善网络超时和条件缓存响应处理，重试保持固定目标版本、下载来源、大小和 SHA256 校验。
- 更新完成与已提交事务续跑同时核验固定版本和源码提交；启动初始化失败显示对应阶段及真实本机日志。
