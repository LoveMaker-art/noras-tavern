# 诺拉·酒馆 v2.6.0

本版本包含启动器 **2.2.8**，Hermes 保持官方 **v0.21.1**。

- 完善 Linux／云端实例支持：诺拉模型配置、技能和核心维护按当前实例定位，支持程序、数据和解释器分开存放，不再要求安装桌面启动器。
- 诺拉和启动器复用 Hermes 模型配置能力，支持查询、验证后保存、切换及受保护的删除；操作结果尚未确认时查询原任务，保留已有配置和输入。
- 默认交付诺拉技能库管理技能，需要扩展能力时查询公开目录并按需安装。
- 诺拉可以调整酒馆的字体、字号、行高和段距；支持全局设置及世界单独设置。优化普通正文的空行显示，内置默认段距为 10px，保留已有个人设置。
- 补齐助手脚本的编辑与保存、导入前图片预览、卡库页码跳转及显示密度调整；各显示模式完整呈现卡片图片。
- 修复创建世界后的进入衔接、预设复制及相关角色设置保存问题。
- 修正 Windows 卡库的符号链接读取边界，以及故事存储路径异常时被误显示为空列表的问题。
- 修正服务启动重试的永久拦截、部分历史恢复记录误阻后续操作，以及无桌面实例的启停与 Linux 维护写锁问题；更新与恢复继续报告各自实际结果。

聊天、角色、世界、模型配置、偏好和历史档案继续保留。云端使用核心更新，桌面保留酒馆和启动器分别交付、统一发起更新的流程。

本版不包含新版历史修复工具，也不宣称已解决所有历史安装的恢复或卸载故障。已有未完成的程序替换仍按对应恢复流程处理。
