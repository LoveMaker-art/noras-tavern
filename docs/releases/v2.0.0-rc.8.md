# Tavern 2.0.0-rc.8 - Restore legacy updater stop behavior

Candidate release for the Nora Tavern 2.0 updater.

## Fixes

- Restores the v1.24.12 updater stop behavior for the Python Tavern runtime.
- Uses the legacy `pkill -f "server.py --port 8799"` stop path instead of failing the update when the stopped listener briefly has no identifiable `/proc` owner.
- Keeps the rc.7 Liveware CLI/PATH fix.

## Update command

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/download/v2.0.0-rc.8/install-tavern-updater.sh | sh -s -- --tag v2.0.0-rc.8 --allow-candidate --apply --confirm
```
