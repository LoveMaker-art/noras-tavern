# 诺拉·酒馆 v2.3.3 · 启动器 1.0.0

## 本次更新

- 三平台启动器统一升级为 **1.0.0**，配套酒馆系统版本为 **2.3.3**。沿用现有界面、诺拉图片及原生应用图标。
- 本地诺拉新增模型配置技能，可通过已有 Hermes 配置接口保存提供商、模型和密钥，并同步启动器的配置记录。仅在本地启动器托管实例安装或更新；普通云端部署不会自动添加该技能。不创建额外备份文件，不自动修改酒馆模型、人格或 IM 配置，不强制重启；新配置供后续会话使用。
- 启动器配对 ClawChat 时，来源标识改为 `type: nora-tavern`，`platform` 仍为 `hermes`。该标识区分接入来源，不等同于精确的安装次数统计，也不追溯修改已经配对的记录。
- 完善安装失败诊断：记录阶段、实际路径、异常调用链、子进程输出、退出码和耗时。回滚、清理或状态保存再次失败时，保留最初的操作错误。启动器无法打开时也会尝试写入备用日志。
- 日志先脱敏再写入，并自动轮转：每份最多 **10 MiB**，每个目录保留 **3 份**；正常和备用目录均使用时合计最多约 **60 MiB**。超长记录分段保存，超出总保留容量的旧记录自动淘汰，不自动上传日志。

## 已有用户如何升级

**日志增强、日志轮转和接入标识属于启动器自身改动，需要安装 1.0.0 才能获得。** 单独更新酒馆内容不会替换旧启动器程序。

1. 下载对应电脑的安装包，退出旧启动器后安装新版。Mac 用新版应用替换旧应用；Windows 运行安装程序，沿用原启动器安装位置。
2. **保留原数据目录，不要执行完整卸载，不要清理 Hermes、密钥、世界或聊天记录。** 正式版沿用原应用标识和已保存的安装位置。
3. 打开新版，在“更多 → 查看版本”将已安装内容更新至 2.3.3。首次安装则按界面完成安装、模型配置和 IM 连接。

本次正式包不沿用 `0.3.5-diagnostics.1` 的独立测试目录。诊断测试用户请保留测试数据；不要将删除数据作为升级步骤。

之后普通内容更新仍通过统一更新器完成，无需每个小版本都重新下载安装包。独立部署继续使用[更新指南](https://github.com/LoveMaker-art/noras-tavern/blob/v2.3.3/docs/update-nora-tavern.md)中的现有入口。

## 验证范围与注意事项

发布流程要求 Mac Apple 芯片、Mac Intel、Windows x64 全部通过原生构建、日志轮转与脱敏测试、模型配置技能测试、首次安装和已安装实例更新检查，并核对包内版本、人格文件、技能和图标。Windows 同时在关闭长路径支持的条件下验证安装与更新。

自动验收不使用个人 API Key 或配对码，不代表每个 IM 平台的真人对话都已重新测试。此前报错用户已反馈诊断测试包安装成功，但不能据此断言所有 Windows `EPERM` 的根因均已解决。

平台包尚未提供商业代码签名及 Apple 公证，系统可能显示安全提示。仅从本仓库下载，不要关闭系统安全防护。发生问题请按[日志收集说明](https://github.com/LoveMaker-art/noras-tavern/blob/v2.3.3/docs/launcher-install-diagnostics.md)提供日志。
