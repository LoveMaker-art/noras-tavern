# Tavern 2.0.12

本次重点：修复 Tavern 运行时恢复死锁，并让每日更新检查脚本在升级时正确刷新。

- 修复 `start`、`stop`、`restart` 和 `prepare` 命令重复获取同一生命周期锁的问题。
- Tavern 进程退出后，Hermes 启动 Hook 可以正常执行恢复命令，不再无限等待自己持有的锁。
- 启动失败的清理路径不再重复加锁。
- 修复更新器对 `tavern-ops/scripts` 目录的路径判断，不再误报“发布包缺少更新提醒脚本”。
- 已安装的 `nora-tavern-update-check.sh` 与每日 09:00 更新检查任务现在会随版本正常刷新。

更新命令：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/latest/download/install-tavern-updater.sh | sh -s -- --apply --confirm
```

安装完成后，在 ClawChat 对话中发送 `/restart`，重新加载 MCP、技能和 AGENTS。
