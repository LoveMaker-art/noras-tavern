# Tavern 2.0.0-rc.9 - Verify Liveware before updater success

Candidate release for the Nora Tavern 2.0 updater.

## Fixes

- Requires the public Liveware app entry to be reachable before the updater reports success.
- Accepts the ClawChat gateway `open in clawchat` response as a valid public-entry signal.
- Restores managed Tavern skills, including `nora-cardforge`, by removing only Tavern-owned skill names from `skills.disabled`.
- Preserves unrelated disabled skills and existing Hermes MCP configuration.
- Keeps the rc.8 legacy runtime stop behavior.

## Update command

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/download/v2.0.0-rc.9/install-tavern-updater.sh | sh -s -- --tag v2.0.0-rc.9 --allow-candidate --apply --confirm
```
