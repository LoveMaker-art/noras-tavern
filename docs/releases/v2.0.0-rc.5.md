# Tavern 2.0.0-rc.5 — 修复 Python 旧版启动脚本误报冲突

本版为预发布测试版，不合并 main，不替用户更新远端机器。
包含 Tavern、Story Profile、Nora MCP、官方技能和更新器。

## 相对 rc.4 的变更

- 修复从 Python v1.24.12 更新时，将官方 `hooks/tavern-liveware-register/run.sh` 误判为用户修改而停止的问题。
- 依据官方历史文件的精确 SHA-256 识别原版启动脚本，同时保留对 rc.2 原版脚本及已受管文件的识别；真正修改过的脚本仍需人工确认，不自动覆盖。
- 迁移测试补齐 Hermes 实际安装的 `hooks/` 目录，不再只测试技能目录内的脚本副本；检查成功替换和回滚后原文件完整恢复。
- 不更改酒馆界面、模型配置、聊天逻辑或 Liveware 绑定策略；保留 rc.4 的资源精简。发布包不携带用户模型配置或密钥，使用目标机器自己的配置。

## 固定版本更新命令

在目标机器执行：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/download/v2.0.0-rc.5/install-tavern-updater.sh | sh -s -- --tag v2.0.0-rc.5 --allow-candidate --apply --confirm
```

仅审查可移除 `--apply --confirm`。不要使用 `releases/latest` 来测试此预发布版。
成功安装后，在 ClawChat 与若棠的对话中发送 `/restart`，按输出完成 MCP 和技能重载。
更新器不自动重启 Hermes。

## 验证与边界

修复已通过本地隔离环境验证：官方旧脚本升级、用户修改保护、完整 Bootstrap Python→Node 迁移、
测试世界/对话/故事档案内容保留、同版本重复更新不重复迁移、手动回滚及启动后故障自动回滚。
这些测试使用合成数据，不调用真实模型，也不更新用户的远端机器。

目标 Linux/ClawNest 的实际更新、ClawChat 界面和网关重载仍需用户验收。
此前限制继续存在：Liveware CLI 无法读取 tunnel 原有上游地址，修改绑定后若后续失败，
未知的原绑定不能自动恢复，需按 `integration-pending` 提示核对；
暂缓处理的 `image-size`、`showdown` 依赖安全问题未在本次解决。
本版不宣称达到稳定版发布标准。
