# 诺拉·酒馆 v2.4.3

本次版本包含启动器 **2.1.0**。

- 安装和更新优先使用 GitHub；遇到限流、访问拒绝或可恢复的网络错误时，自动切换到 SourceForge 下载同一版本、同一文件，继续核验大小和哈希。
- 安装、更新和恢复共用执行边界，避免同时修改同一安装。失败后按实际备份和事务状态提供恢复入口，限制无条件重复执行。
- 启动器内可直接查看本次操作的实时原始日志和调用位置。详细诊断开启时，仅失败或中断操作自动上传整次脱敏日志，支持断网后续传。
- 错误提示区分网络等待、配置问题、恢复条件不足和未知故障，并提供对应操作。
- 保留原版界面，修正菜单、服务启停和状态刷新导致的正文移动、滚动区域及控件遮挡。
- 酒馆启动健康等待延长至 120 秒，进程提前退出仍立即报告失败。
- 独立更新脚本支持备用源，并在下载前固定本次版本，防止混用不同发布文件。
- 聊天滚动备份独立执行，减少正常游玩对备份时机的影响。
- 修正 Windows 短路径被误判为备份目录变化、启动器安装凭据不一致及存储清单路径不一致的问题，保留恢复前的目录身份和文件校验。
- 修正系统时钟回拨造成的备份排序和保留冲突，确保新备份仍按实际保存顺序排列。

新执行协议需要启动器 2.1.0；不通过绕过身份或备份核验来接管不明确的旧安装。升级保留聊天、世界和已有配置。详细日志开关的新选择默认开启，已有主动关闭选择保留；不收集聊天、模型回复、密钥或日常服务日志，基础阶段统计继续上报。
