# Tavern 2.0.0-rc.7 — 修复 Hermes 终端找不到 Liveware

预发布测试版。包含 Tavern、Story Profile、Nora MCP、官方技能和更新器。
不合并 main，不自动更新用户机器或重启 Hermes。

## 本次变更

- 修复 Hermes 隔离 HOME 的登录 shell 重置 PATH 后，更新器找不到 ClawNest 自带 Liveware、转而执行不存在下载副本的问题。
- CLI 查找统一覆盖显式 `LIVEWARE_BIN`、当前 PATH、`/opt/clawnest/bin/liveware` 和目标机器插件下载目录，并验证文件可执行。显式错误配置会明确停止，不静默换用其他安装。
- 更新器及其调用的 ClawChat 插件共享选定程序的子进程 PATH；不修改用户 shell 配置，不下载第二份 CLI，不修改 Hermes 源码。
- 程序不存在、执行权限和系统启动错误保留具体路径及 errno，不再只报告笼统的“无法启动”。
- 更新技能改为开始时一句提示、过程只保留终端日志、结束时一条总结。该回复规则须安装新版并重载技能后生效，不能改变正在使用旧技能的会话。
- 用户模型配置、数据迁移、App 身份、回滚和用户 `/restart` 流程不变。

## 更新命令

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/download/v2.0.0-rc.7/install-tavern-updater.sh | sh -s -- --tag v2.0.0-rc.7 --allow-candidate --apply --confirm
```

安装成功后，在 ClawChat 中发送 `/restart`。

本次针对已复现的 CLI 查找和子进程 PATH 缺陷进行验证，并执行发布构建与文件校验。

rc.6 的既有迁移/回滚边界继续适用，未再次展开独立迁移演练。
