# Tavern 2.2.1

本版本修复 Tavern 2.2.0 更新过程中 Liveware 启动钩子安装失败的问题。

- 启动钩子会在目录替换前复制到独立暂存区，避免 `ops` 目录先移动后使钩子来源失效。
- 保持现有备份、回滚、用户数据保留和增量更新逻辑不变。
- 已在真实 Tavern 2.1.7 远端安装上完成升级验证；Tavern、Story Profile、Liveware、世界、角色和模型配置均正常。

更新命令：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/latest/download/install-tavern-updater.sh | sh -s -- --apply --confirm
```
