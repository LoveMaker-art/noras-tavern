# Tavern 2.0.4

本次重点：修复手机端软键盘弹出后遮挡 Tavern 输入框的问题。

- 使用移动 WebView 的可视视口高度和顶部偏移控制 Nora 主布局，不再仅依赖布局视口高度。
- 键盘弹出、收起、页面滚动和横竖屏切换时同步更新布局，使底部输入区保持在当前可见区域内。
- 不支持 `visualViewport` 的旧浏览器继续使用 `innerHeight`，桌面端布局保持原有行为。
- 已重新生成生产前端构建产物，并加入移动视口契约测试。
- 本版本不修改 World、聊天、MVU、模型、Story Profile、MCP、技能或更新器逻辑。

更新命令：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/latest/download/install-tavern-updater.sh | sh -s -- --apply --confirm
```

安装成功后，在 ClawChat 对话中发送 `/restart` 加载新版本。
本版本不会附带开发者模型、密钥或用户数据，也不会自动更新任何用户机器。
