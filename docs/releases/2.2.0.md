# Tavern 2.2.0

本版本集中改善移动端启动兼容性、Liveware 注册一致性和生产运行稳定性。

- 为旧版 Android WebView 增加模块加载兼容层，解决部分手机停在启动阶段或显示空白酒馆的问题。
- Liveware 更新时按应用身份收敛重复 Tavern 条目，并让入口绑定到当前静态资源版本。
- 启动遥测遇到过期 CSRF token 时自动刷新一次，不再因一次 403 干扰启动诊断。
- 生产环境关闭高频访问日志和 DEBUG 请求体输出，只保留失败、超时与关键启动事件。
- 性能诊断日志改为有界轮转，减少长时间运行后的磁盘占用。

更新命令：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/latest/download/install-tavern-updater.sh | sh -s -- --apply --confirm
```
