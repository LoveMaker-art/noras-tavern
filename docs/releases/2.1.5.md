# Tavern 2.1.5

本版本改善 Tavern 的启动与恢复体验，并修复 MVU 旧数据的识别。

- 先显示轻量世界列表，只在打开世界或恢复上次世界时加载完整 Tavern 运行时。
- 首次使用停留在世界选择页；后续打开会自动恢复上次成功进入的世界。
- 分离核心、扩展和稳定库资源的内容哈希，避免更新后加载旧前端或重复下载未变资源。
- 旧版 MVU 世界只要已有有效变量快照，即可正确识别为已初始化。
- 发布哈希同时覆盖 Brotli/Gzip 稳定库资源，确保不可变缓存与实际传输内容一致。

更新命令：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/latest/download/install-tavern-updater.sh | sh -s -- --apply --confirm
```
