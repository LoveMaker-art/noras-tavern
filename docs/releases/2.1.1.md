# Tavern 2.1.1

本次重点：修复从旧 Python Tavern 迁移到新版 Node Tavern 时，旧进程未被更新器可靠停止而导致端口占用、更新回滚的问题。

- 更新器现在会根据 `server.py` / `server.js` 的真实命令路径识别 Tavern 运行时进程，不再只依赖进程 cwd。
- Supervisor 托管服务发现现在接受 app 子目录作为服务目录，也接受 command 中指向 Tavern app 内 server 的配置，避免漏停旧服务或被 supervisor 重新拉起。
- 新增回归测试覆盖旧 Python server 从 app 目录外启动、同端口无关进程不被误杀、托管服务目录/命令识别等场景。

更新命令：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/latest/download/install-tavern-updater.sh | sh -s -- --apply --confirm
```

安装完成后，在 ClawChat 对话中发送 `/restart`，重新加载 MCP、技能和 AGENTS。
