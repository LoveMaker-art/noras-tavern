# Tavern 2.0.10

本次重点：把 Tavern 新版本检查正式纳入发布与更新流程。

- 新增每日 09:00 的程序化版本检查任务，不调用模型、不消耗模型额度。
- 直接比较本机版本与 GitHub 最新稳定 Release；没有新版本时保持静默。
- 同一个最新版本只提醒一次，检查失败会写入本地日志，不伪装成成功提醒。
- 更新器会同步更新检查脚本，并幂等创建或修正同一个 Hermes cron 任务，不会重复注册。
- ClawChat 提醒明确使用“更新 Tavern”，避免误触发 Hermes Agent 自身更新。
- 定时任务只负责提醒，仍需用户明确同意后才会执行正式更新。

更新命令：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/latest/download/install-tavern-updater.sh | sh -s -- --apply --confirm
```

安装完成后，在 ClawChat 对话中发送 `/restart`，重新加载 MCP、技能和 AGENTS。
