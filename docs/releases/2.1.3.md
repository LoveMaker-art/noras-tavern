# Tavern 2.1.3

本次重点：修复导入 MVU 角色卡后变量长期显示“未就绪”的首次激活问题。

- 在 World 聊天生命周期开始前加载 Tavern Helper 与 Nora MVU，确保 MVU 不会错过 `CHAT_CHANGED` 初始化事件。
- 将聚合快照中的新世界书同时注册到内容缓存和运行时名称表，使新导入卡无需刷新页面即可读取 `[InitVar]`。
- 保留角色卡原始世界书、变量格式、显示规则和前端样式，不修改用户世界与聊天数据。
- 增加首次导入和重复注册回归测试。

更新命令：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/latest/download/install-tavern-updater.sh | sh -s -- --apply --confirm
```
