# Tavern 2.0.0-rc.3 — 更新器重构测试版

这是预发布测试版，不是正式稳定版。本次发布不合并 main，不替用户更新远端机器。
Tavern、Story Profile、MCP 和官方技能包含在同一份经过摘要校验的发布包中。

## 本次变更

- 更新统一使用整目录事务；旧的逐文件更新逻辑只保留历史回滚能力。
- 审查、应用、回滚使用同一份固定且校验过的更新器快照。
- 生命周期与更新器共享进程身份校验和维护锁；不再只凭陈旧 PID 文件判断进程。
- 下载、检查、准备、维护和恢复阶段直接输出脚本进度，不需要模型参与执行。
- 同一版本、同一文件内容的重复更新不再重复停服或迁移。
- 首次创建 Liveware App 与更新现有 App 分离；更新和启动恢复不会创建额外 App。
- 移除旧的网关确认桥接安装逻辑；安装成功后提示用户在 ClawChat 发送 `/restart`。
- 发布包不包含用户模型配置或密钥；模型配置只能来自目标机器。
- Python 数据在副本上迁移，再执行事务切换；现有 Node 数据保留并验证。

## 固定版本测试命令

在目标机器执行：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/download/v2.0.0-rc.3/install-tavern-updater.sh | sh -s -- --tag v2.0.0-rc.3 --allow-candidate --apply --confirm
```

只审查、不应用：移除末尾的 `--apply --confirm`。
不要使用 `releases/latest` 来测试此版本，该地址可能仍指向旧的稳定版。
成功安装后，按输出提示在 ClawChat 发送 `/restart`；更新器本身不重启 Hermes。

## 验证边界与已知限制

本地已验证更新器单元测试、事务重命名中断恢复、隔离 Node 更新和回滚、
原 Python 离线数据经 Bootstrap 迁移、重复安装与启动后失败回滚。
这些验证不等同于目标 Linux/ClawNest、在线原 Python 服务、ClawChat 页面和网关重载验收。

**Liveware 绑定回滚仍有限制：** 当前平台接口不能读取 tunnel 原有的本地上游地址。
若修改绑定后发生后续失败，本地文件可回滚，但不能猜测并自动恢复未知的原绑定。
更新器会记录 `integration-pending` 并阻止继续更新/启动恢复，需要人工核对绑定。
正常绑定的 CLI 成功回执与本地页面校验，也不等同于已验证带鉴权的外网入口。

稳定发布所需的目标环境验收尚未完成；此前暂缓的 `image-size`、`showdown`
依赖安全问题也未在本次解决。本版仅供明确授权的预发布测试。
