# Windows 启动器网络与生命周期测试

## 本次改动

- 版本查询和组件下载改用 Electron Chromium 网络栈，保留证书验证与文件完整性校验。
- 安装前增加真实 GitHub 版本接口的 Chromium / Node 对照诊断，并检查正式版 Windows 系统清单；结果写入 `install.log`，不记录 Key 或响应正文。
- 完全退出启动器前停止当前实例的诺拉和酒馆；停止失败会提示，不批量结束其他实例。
- 已安装实例打开启动器时仅自动尝试启动酒馆一次，手动停止后不被轮询反复启动。
- 首次模型验证后保存同步进度；酒馆同步失败可以继续，无需重新输入 Key 或再次调用模型验证。
- 自定义模型支持获取模型列表和明确选择无需鉴权；连接测试仅验证文字响应，工具调用能力未验证。
- 保留子进程的具体失败原因，修正同一 Node 可执行文件通过链接路径启动时的进程识别。
- 首次安装仅对尚未设置的 `approvals.destructive_slash_confirm` 设置默认值 `false`，保留用户显式配置。

## 测试边界

此包来自 `codex/launcher-lifecycle-improvements`，仅用于 Windows x64 测试，不是正式更新，不改变正式版 latest。

使用独立候选数据目录，不覆盖正式版世界、模型配置或 Hermes。通过联网检查后安装包内置的候选系统；安装成功不代表远程大文件下载已在用户网络验证。候选包不支持在线升级。

请重点验证此前报证书错误的电脑是否通过连接检查，以及安装、模型同步和退出服务的流程。若失败，请提供本次测试目录 `installer/install.log`；不要删除正式版数据或关闭证书校验。
