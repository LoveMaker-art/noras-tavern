# 诺拉·酒馆 v2.3.11

## 本次更新

- 启动器升级至 1.1.0：统一检查酒馆与启动器版本，按需下载系统组件或轻量启动器更新包。
- 首次安装优先使用安装包内已校验的资源，不再以成功查询 GitHub 最新版本作为开始安装的前提。
- 本地更新与更新技能共用更新流程，保留安装路径、世界、聊天及模型配置，不重新部署整个 Hermes 环境。
- 加强更新事务保护：更新前检查服务状态，启动验证失败时恢复旧文件和原服务状态；未完成的恢复会保留备份并阻止继续覆盖。
- 已安装但技能文件损坏时进入修复流程，不再误当作首次安装；修复完成后清除旧的待恢复状态。
- 完善网络错误、进程退出及安装失败日志；调整 Windows 关闭窗口和启动器替换过程，降低目录占用造成的失败。
- 加强三平台包的源码、版本、模板和轻量更新归档一致性校验。

## 兼容说明

- 旧启动器尚未具备新版自替换能力时，需要先手动覆盖安装新版启动器；保留原数据目录。
- Windows 便携版暂不支持启动器自动替换，请使用安装版。
- 断电或强制结束进程后的未完成事务会保留备份并提示恢复，不承诺所有中断都能自动回滚。

## 验证范围

本机 Mac Apple 芯片已验证隔离首次安装、跨版本更新及世界和聊天保留。三平台发布流水线另行执行原生构建、安装更新检查、失败恢复测试及归档校验；不等同于所有设备的桌面交互和真实 IM 收发实测。
