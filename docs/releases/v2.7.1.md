# 诺拉·酒馆 v2.7.1

本版本将诺拉、酒馆、MCP 与核心部署维护收拢为独立核心，不包含新的桌面启动器版本。

- 普通核心更新默认使用轻量组件构建，不再强制重新构建三套 Hermes 运行环境；需要完整原生交付时仍可选择 `native` 验收。
- 保留现有安装路径、核心更新入口、制品摘要、失败续传和存量客户端兼容资源。
- 修复 Windows 校验固定维护输入时，GNU tar 将驱动器盘符误当成远程主机的问题，改用平台原生归档工具。
- 修复模型候选验证缺少停滞截止的问题，并改善 Windows 系统信息输出的编码读取。
- 修复首次安装组件探测可能超出预期等待时间的问题。
- 整理核心安装、运行、更新和恢复文档，明确已有 Hermes 实例与源码部署的使用边界。

本次发布只推进核心 stable 渠道，不修改桌面启动器渠道。
