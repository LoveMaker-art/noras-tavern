# Tavern 2.0.3

本次重点：收敛用户安装包中的可选资源，降低更新下载与解压成本，同时保留复杂角色卡、MVU、脚本系统和 Story Profile 主链路。

- 所有模型专用 tokenizer 不再随安装包发布；缺少精确 tokenizer 时使用保守近似计数，DeepSeek、Qwen 等可下载 tokenizer 仍会按原逻辑缓存。
- 运行包只保留英文、简体中文和繁体中文资源；Nora 继续跟随 ClawChat 的中英文语言状态。
- 移除 PDF、EPUB 及其 JSZip 解析库，并从文件转换器中取消对应格式，避免缺少资源时产生延迟加载错误。
- HTML、Markdown、Office 文档逻辑保持不变。
- JS-Slash-Runner、Nora MVU、角色卡脚本、世界书和 Story Profile 均保持原有能力。
- App 发布包由约 20.84 MiB 收敛到约 12.65 MiB；实际大小以该版本 Release 资产为准。

更新命令：

```sh
curl -fsSL https://github.com/LoveMaker-art/noras-tavern/releases/latest/download/install-tavern-updater.sh | sh -s -- --apply --confirm
```

安装成功后，在 ClawChat 对话中发送 `/restart` 加载新 MCP 和技能。
本版本不会附带开发者模型、密钥或用户数据，也不会自动更新任何用户机器。
