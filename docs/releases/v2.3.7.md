# 诺拉·酒馆 v2.3.7

## 本次更新

- 保护未保存的编辑内容：编辑角色、世界设定、模型等内容时，点击面板外部不再直接退出；有修改时关闭或返回需确认，保存失败保留输入。
- 加强世界数据隔离：新建世界使用独立的角色卡和世界书副本；添加设定追加到当前世界，不再替换原世界书。已有世界不做批量迁移，后续编辑按隔离规则处理。
- 诺拉可以创建、编辑、应用和另存预设，并通过工具导入不超过 10 MiB 的 JSON 预设文件，不再受普通控制参数大小限制阻挡。
- 清理空角色列表的误导入口：没有角色设定时保留“添加第一条设定”，不再通过空白编辑按钮打开整张卡的基础资料。
- 修复更新技能选择 Python 环境的问题，先定位 Hermes 运行环境，减少因误用系统 Python 导致的缺依赖失败。

## 使用提醒

- 更新后请刷新已打开的酒馆页面，使新前端生效。
- 本次不包含独立测试中的启动器生命周期改动，也不包含针对个别角色卡的 MVU 改造。
- 不主动清空世界、聊天或模型配置；未承诺解决模型输出格式错误及所有网络超时。

## 验证范围

已对编辑保护、空角色入口、世界隔离和预设接口进行针对性测试；界面修复已部署测试机并检查服务及资源。发布流水线另行验证组件完整性、环境复用与更新数据保护，不等同于所有设备和角色卡的完整实测。
