# 安装 Nora + Tavern

[返回项目首页](../README.md) · [下载启动器](../README.md#下载安装包) · [只安装酒馆](install-tavern.md)

完全版包含诺拉酒馆本体，以及帮你管理酒馆、可以互动的诺拉。以下步骤适用于 Windows x64、Mac Apple 芯片和 Mac Intel。

**准备好网络和自己的模型 API Key。** Hermes、Python、Node.js 及必要依赖由整合包提供，不需要先手动安装。

## 第一步：下载并打开

1. 前往[首页下载区](../README.md#下载安装包)，点击与你电脑对应的安装包链接。
2. **Mac**：打开下载的 DMG，把“诺拉·酒馆”拖入“应用程序”，再从“应用程序”打开。不要一直在 DMG 中运行。
3. **Windows**：双击下载的安装程序，按提示安装并打开“诺拉·酒馆”。

不知道选哪个？Mac 在苹果菜单“关于本机”中查看芯片；Windows 选择 x64 包。Windows ARM 暂不作为原生支持平台。

> 当前安装包未经 Apple 公证或 Windows 发行商代码签名，系统可能提示安全警告。请仅从本仓库发布页下载，按发布页校验信息核对文件，不要关闭系统整体安全保护。

## 第二步：安装诺拉与酒馆

1. 在启动器中确认安装位置。默认位置即可；需要改位置时，点击文件夹图标选择。
2. 点击 **安装酒馆**。
3. 等待自动安装完成，界面会进入模型配置，不需要反复点击。

诺拉和酒馆放在同一个专属目录中。安装途中提示失败时，保留错误信息，按界面提示重试，不要先删除整个安装目录。

## 第三步：配置模型

1. 选择模型服务。使用中转服务时，选择 **自定义**，填写该服务提供的 API 地址。
2. 填入自己的 **API Key**。
3. 选择或填写模型名称，名称以服务商提供的模型 ID 为准。
4. 点击 **连接并继续**，等待测试成功。

失败时先核对服务商、API 地址、Key、模型名称和账户余额，再重试。此配置也用于初始化酒馆模型；调用模型时，Key 和对话请求会发送给你选择的服务。

## 第四步：连接 IM 平台

**本整合包当前的配对流程使用 ClawChat，并非任意 IM 平台都能直接接入。**

1. 点击[下载 IM 客户端](https://clawling.com/zh/chat/#get)，完成安装和登录。
2. 打开[获取配对码的图文指引](https://clawling.com/zh/chat/docs/connect-code/)，在客户端注册 Hermes Agent，取得配对码。
3. 回到启动器，只粘贴配对码，不要粘贴整条激活命令。
4. 点击 **连接并继续**，等待启动检查完成。

配对码过期或已经使用时，重新获取。连接、应用入口注册由启动器处理，不需要手动复制脚本。

## 第五步：开始使用

- **进入酒馆**：点击启动器的 **打开酒馆**。
- **与诺拉对话**：在 IM 客户端联系人中找到诺拉，发送“你好”。
- **从聊天中进入应用**：点击诺拉聊天页右上角的四格图标，选择 **Tavern** 或 **Story Profile**。Story Profile 记录你的喜好，也能修改诺拉的人设。

> 诺拉和酒馆运行在你的电脑上。电脑关机、休眠、断网或相应服务停止后，对话或应用入口可能无法使用。关闭启动器窗口后服务可以继续运行；需要停止时，请在启动器中操作。

## 下次使用

直接打开启动器即可，不必重新安装。诺拉和酒馆可以分别启动、停止。
