## Tavern 本体新手开场补齐（源码，尚未重新打包）

用户确认的是参考机器中「新手引导」世界的首条消息，不是 Hermes / ClawChat 的 `greeting.md`。
原测试包未包含这份世界运行数据；修复不复制远端存档，而是将确认的中文正文纳入 Tavern 源码资源。

- Tavern 在监听 HTTP 前为没有世界、角色卡、会话、世界书或已保存世界选择的工作区初始化「新手引导」。
- 通过现有 World Core 创建真实角色卡和初始会话，并设置首次默认打开的世界，沿用现有聊天显示与世界切换逻辑。
- 不调用模型，不依赖 ClawChat 发消息；不自动导入两则可选故事。
- 初始化完成后不重写正文、聊天或世界选择；删除引导后不会重新生成。已有资源的工作区跳过初始化。
- 初始化记录和 World Core 的同一操作标识用于中断恢复，避免在世界已提交、设置尚未保存时重复创建。
- 中文正文加入发布必备文件校验，发布文件筛选测试覆盖正文和初始化模块。

验证边界：真实文件系统及角色卡编解码测试覆盖首次初始化、首条中文消息、默认选择、重复/并发启动、保留进度、删除、中断恢复和已有数据保护；相关导入与启动定向测试 45 项通过。
本轮未替换桌面测试包、未改动用户测试实例或远端机器，也未进行新包的可视化验收。
