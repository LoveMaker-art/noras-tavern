## 修复与整合取舍

1. **通用 world.update 授权边界**：限制为世界内容字段；禁止夹带 preset、脚本执行权限、内部删除命令，混合补丁同样拒绝。正常预设编辑继续走专用入口。
2. **预设编辑预览**：收起文本框时从当前草稿刷新文本预览，重新展开仍保留草稿；清空内容也同步；不自动保存，不执行 HTML。
3. **组合交付**：保留新版界面和世界预设投影，同时接入脚本持久化与启动优化；重新生成全部受影响前端资源，包含新增 947.js，检查压缩文件一致性。
4. **模块职责**：入口从整合前 570 行收敛至 500 行（基线 main 原为 529 行），没有扩大 500 行门槛。消息桥和图标归于已有 shell 模块，插件加载、账本请求、checkpoint 分别归于已有所属模块。消息控制器保持延迟读取；插件列表保留多元素选择器。
5. **后端隔离**：scriptCode/regexCode 比较函数移入纯预设数据模块，后端不再导入含浏览器全局投影的模块。preset-file 加入纯模块依赖检查，并继续禁止浏览器和 I/O 依赖。
6. **测试夹具与旧约束**：补齐已有 protectForm 的测试替身；世界摘要夹具注入真实扩展控制器。旧 shell 约束已与基线产品不符，改为检查详情页删除入口、World 概要排除与旧卡字段兼容、按条目保存和共享模型投影，而非恢复被替代的 UI。
7. **仓库卫生**：忽略依赖符号链接与根目录临时 dist；不纳入依赖、临时构建目录、个人 research 文档；移除本批新增且无引用的 32 条翻译键，未广泛删除历史词条。
