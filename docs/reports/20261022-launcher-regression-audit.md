# 启动器回归测试审查与清理

日期：2026-10-22。比较起点：`5ecf08f`；分支：`codex/regression-audit-20261022`。产品设计1.33保持。用户授权审查回归测试、清理有证据支持的冗余，安装／更新／恢复／卸载验收不得削弱；不调用子智能体，不打包或发布。执行记录在[原任务](../launcher-reliability-plan.md#regression-audit-20261022)。

## 范围与判断依据

核对完整稳定性入口、`tests/deployment`的81份JavaScript与65份Python文件、历史夹具、公共辅助及三份工作流的引用。JavaScript语法树记录1157处测试声明，Python记录861个测试方法；声明、参数化后的runner计数和实际平台工作流分别统计。数量不作为有效性结论。

重复判定核对调用的实现、前置条件、注入故障及断言，不能仅比较名称或函数正文。过期判定以当前入口、设计和可复现结果为依据。无法执行的原生／制品检查明确保留，不能删掉后宣称通过。

## 保留依据

- 语法树未发现JavaScript同名测试或完全相同回调；Python发现三处`self.transaction()`相同正文，实际调用三个不同夹具，分别验证受管更新、残缺修复及目标校验，全部保留。未发现导入其他TestCase造成重复收集。
- `test_update_space`检查容量计算／卷归属，`test_update_space_contract`检查真实事务在停服前后拒绝及恢复，属于不同层次。内存单元锁、实际原生写锁、运行中执行者归属和最终APP身份也分别保留。
- `published-v2.4.4`是带来源摘要的冻结协议样本，`clawchat-greeting-before`是升级前行为样本，均有实际消费者；旧版号不是过期依据。非法输入、缺失文件、未知效果等负例保留。
- 同一文件在源码Python与实际密封Hermes上下文重复执行，或Node与Electron／物理ASAR分别执行，仍有不同验收依据。平台专属条件与缺制品输入单独登记，不改为无条件通过。

初轮Python目录发现因两份模块相对导入失去包身份报错；尝试直接传源码根目录也被投影入口拒绝。这些是本次审查命令的执行方式错误，记录保留，未改产品代码或删除失败模块。最终用63个明确的`tests.deployment.<模块名>`完整运行并通过；导航只推荐已验证的模块入口。所有早期失败不计为通过。

跳过与未验：扩展JS的18项为接收端／原生崩溃输入未提供；Python9项中6项要求Windows，另3项分别缺真实替换归档、ClawChat插件输入及Linux `/proc`。当前门禁中的2项Windows跳过已包含在扩展Python9项中，不另算新缺口。真实窗口、三平台最终安装包、Windows/Intel实机、外部ClawChat与模型调用未在本轮重验；保留其原入口和既有平台门禁，源码结果不能代替这些验收。

## 清理后的边界

移除同环境的一次重复整组执行、合并重复文案断言、修正失效计数，并扩大既有门禁对重复执行和缺失文件的检查。没有删除测试文件、缩减安装／更新／恢复／卸载用例矩阵、取消故障分支、增加skip或延长超时；完整主回归数量仍为959＋357。未发现可证明没有用途而应整份删除的部署测试文件；不据此保证以后不会出现过期测试或已穷尽所有语义重叠。

逐文件清单为忽略目录内`per-file-audit.tsv`，语法树候选、源文件身份与执行日志一并留存。不把名称相近、历史版号或缺平台输入视为冗余。不保留新的永久审计框架；本轮一次性扫描和故障变体驱动随必要证据归档，临时入口清除。产品运行代码、版本、依赖锁及正式数据未修改。上述审查完成时尚未合并；随后已按用户授权将测试清理与发布流程修订合入本地main，证据迁至主线`local-state/worktree-cleanup-20261022/evidence/regression/`，见[合并清理记录](../launcher-reliability-plan.md#regression-main-cleanup-20261022)。未推送主线、构建安装包、上传或发布。
