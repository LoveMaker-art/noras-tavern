## 发现、定位与修正

1. **执行环境准备。**第一次完整维护入口在测试前因PATH缺npm返回环境错误。接回本机已有npm并重新通过source预检后，完整组通过。第一次浏览器文件未找到Playwright，未启动浏览器；在用户授权后使用已有明确运行路径执行，未新增产品依赖。
2. **UI反馈旧夹具。**四项用例在进入原业务断言前，被只接受`[data-retry-at]`的DOM替身拒绝；生产控制器已查询`.model-mutation`和`.model-recheck`。单文件先复现红，再补充实际类名识别和已有状态变量。原反馈、草稿、服务与诊断断言全部保留，并加强状态未知时禁写、可重查及恢复后继续编辑断言。9项定向与201项组合均通过。
3. **PTY向导旧夹具。**原场景复制了技能和模型组件，遗漏实际安装会交付的`scripts/nora-instance.py`，所以在PTY判断之前返回“当前核心缺少实例定位组件”。单项复现后只补入真实定位脚本，不改生产校验、不伪造结果。原有无PTY拒绝、候选验证前正式文件不变、验证失败保留、成功提交、密钥不外泄及候选清理断言全部保留；单项及18项整文件通过。

本轮只修改上述两份测试夹具，没有更改产品运行源码。完整维护组与已通过的其他功能输入未变，因此保留其结果，仅重跑受影响的文件／组合；不因夹具修正重新构建或重复全套检查。
