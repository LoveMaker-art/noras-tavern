# 核心更新与恢复

诺拉与酒馆核心更新通过本实例的独立核心任务执行；由用户对话授权或明确的维护命令发起。任务固定目标、来源、资产摘要、实例和操作身份，执行准备、停服、替换、核验及需要时的恢复。

<a id="先选择你的安装方式"></a>
<a id="desktop-edition"></a>
## 选择方式

- Git源码运行的酒馆：按 [源码安装](install-tavern.md) 的分支和依赖锁更新，先保留当前修改及用户数据。
- 已受管的诺拉与酒馆：使用当前实例的 `nora/skills/system/tavern-updater/` 入口，检查目标和实际能力后再授权。
- 旧技能缺少独立维护入口：按[独立接入指南](update-standalone-tavern.md)核对正式资产和摘要，不执行来源不明的脚本。

更新对象为核心程序。不得把用户会话、世界、角色、偏好或当前配置是否等于旧快照作为维护资格。失败与中断的恢复要分别验证文件、配置、服务可用性和原任务结束；保留原始原因，不用重试覆盖未知效果。

实现及测试层次见 [核心维护合同](core-maintenance.md)，发行要求见 [发布流程](release-process.md)。
