# 启动器覆盖升级兼容性验收

记录日期：2026-09-21。状态：本地源码及自动化检查通过，尚未发布，也未完成本轮三平台实机验收。

## 验收目标

安装新版启动器后，已有完整系统使用共享更新器升级到包内对应版本，不将当前旧版本误作目标。不重新执行首次安装，不清空世界、聊天或配置。失败后停止自动重试，事务内失败恢复备份；恢复失败保留日志和备份，阻止继续更新。

## 已检查的历史差异

对照本地 Git 标签中的首次安装源码：v2.2.4、v2.2.8 与 v2.2.11 之后的安装记录不同。后者包含 installed.json、nora-system.json 和 nora-instance.json。版本号本身不能证明用户目录仍具备完整记录。

GitHub 发布列表确认 v2.2.11、v2.3.0 至 v2.3.7、v2.3.13 已正式发布；v2.3.8 至 v2.3.12 只有构建标签，不算已发布用户基线。

## 尚需验收

- Windows x64、Mac Intel、Mac Apple 芯片分别使用真实旧安装，再覆盖安装修复后的新包。
- 测试默认目录、自选目录、中文及空格路径、运行中升级、网络中断及重新打开后的手动重试。
- 核对旧世界、聊天与模型配置；验证服务真实启动失败后的旧版恢复。
- 早期无系统安装记录的部署需单独确认迁移策略，不承诺所有历史版本自动升级。

不能将版本号矩阵测试视为所有历史运行时、插件和用户自定义环境均已兼容。
