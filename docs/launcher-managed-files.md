# 诺拉配置文件管理说明

[返回安装指南](install-nora-tavern.md) · [返回更新指南](update-nora-tavern.md)

本页供自行修改诺拉人格或规则的用户参考。普通安装无需编辑这些文件。

## 文件与备份

启动器管理本次专属目录内的 SOUL、AGENTS、技能、MCP、Hook 和更新提醒任务，不复用另一套独立 Hermes 的配置目录。目录隔离不等于操作系统沙箱。

- **AGENTS.md**：首次安装和更新由项目整份管理，替换全文，不保留旧文件中的附加规则。内容变化时，`AGENTS.md.bak` 只保留上一份；失败事务恢复原文件和原备份。需要长期保留的私人信息不要写进此文件。
- **SOUL.md**：识别默认 Hermes 人格并初始化为诺拉；已有自定义人格按保护策略处理，不因普通重试随意覆盖。
- **开场白**：项目受管版本随更新刷新；已有自定义版本保留，新模板写入 `clawchat/greeting.nora-example.md` 供参考。
- **用户数据**：模型 Key、会话、记忆、Story Profile 与程序文件分开处理，不包含在公开安装包中。

## 两套开场内容

IM 中诺拉的开场白与酒馆内部的新手开场是独立内容。前者跟随诺拉连接流程，后者只在空白酒馆实例中初始化，不覆盖已有世界或聊天。

酒馆入口卡片由后台核验当前实例后发送，不通过开场白重复发送；卡片与文字不保证先后顺序。
