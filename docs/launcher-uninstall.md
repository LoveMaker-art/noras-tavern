# 卸载诺拉·酒馆

[返回项目首页](../README.md) · [只是想更新？请看更新指南](update-nora-tavern.md#启动器完全版)

本页适用于通过启动器安装的完全版。**更新启动器不需要先卸载，更不需要删除数据。**

## 第一步：打开卸载入口

打开启动器，选择 **更多 → 卸载诺拉·酒馆**。首次安装未完成时也可进入卸载。

Windows 也可以从系统“已安装的应用”中找到“诺拉·酒馆”并卸载，后续会进入同一套数据选择流程。

## 第二步：选择是否保留数据

| 你的目的 | 选择 | 会发生什么 |
| :--- | :--- | :--- |
| 移除程序，之后还想接着玩 | **保留数据卸载** | 删除启动器、Hermes、酒馆程序和缓存；保留世界、角色、聊天、配置、Key 及已有备份 |
| 连同本次安装的数据一起清空 | **彻底卸载** | 删除确认窗口所示安装目录内的程序与数据，包括 Key、连接凭据和备份 |
| 暂时不卸载 | **取消** | 不开始卸载 |

**彻底卸载无法撤销。** 必须核对窗口显示的路径，并在第二次确认时再次同意。需要保留的内容，请在此之前备份到安装目录之外。

## 第三步：等待完成

卸载会先停止当前安装的诺拉、酒馆及相关服务，再清理文件。停止失败时会中止，不会继续删除。

- **Windows**：跟随卸载窗口提示完成操作。
- **Mac**：请从“应用程序”中已安装的 App 发起，不要在 DMG 内操作。启动器退出后，由辅助程序完成清理并显示结果。

直接把 Mac App 拖入废纸篓，不会自动清理诺拉与酒馆的数据目录。

## 之后想重新安装

- **保留数据卸载后**：从[下载区](../README.md#下载安装包)获取启动器，使用同一通道并指向原安装目录，再按[安装指南](install-nora-tavern.md)操作。
- **彻底卸载后**：按全新安装处理，需要重新配置模型和连接 IM 平台。
- **原目录在外置磁盘上**：先接入磁盘；没有识别到旧数据时，不要覆盖或清空目录。

## 不会一并删除的内容

- 你另外安装的 Hermes、其他酒馆实例和 IM 客户端。
- 云端联系人、服务商账户或 API Key 的有效性。删除本地 Key 文件不等于撤销 Key；需要撤销时请到服务商后台操作。
- 下载目录中保留的 DMG、EXE 等原始安装包。它们不是运行数据，可自行保留或移除。

## 卸载失败怎么办

保留错误提示和实际安装路径，不要手动删除其他目录或反复强制卸载。[反馈问题](https://github.com/LoveMaker-art/noras-tavern/issues)时注明系统、版本、选择的数据保留方式，并移除密钥等私人信息。

<details>
<summary>Windows 错误记录位置</summary>

系统临时目录中可能生成 `nora-uninstall-result.json`，记录辅助程序的结果。它不是整个 Hermes 日志目录；发送前仍应检查并隐去私人路径或信息。

</details>
