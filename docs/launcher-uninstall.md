# 卸载诺拉·酒馆

在启动器中选择 **更多 → 卸载诺拉·酒馆**。未完成首次安装时也可进入卸载。

## 两种方式

- **保留数据卸载**：移除启动器、Hermes 和酒馆程序、下载缓存；保留世界、角色、聊天、记忆、配置及本地 Key。已有备份也保留在原隔离目录内。重新安装到同一目录后恢复使用。
- **彻底卸载**：移除程序，并删除确认窗口显示的隔离目录，包括本地 Key、ClawChat 连接凭据及备份。需要再次确认，无法撤销。

卸载前会停止当前安装的诺拉、酒馆和 Liveware 服务。停止失败则中止，不删除文件。Hermes 的定时任务及启动 hook 随 Hermes 停止运行；保留数据时其配置仍保留。

不会卸载用户独立安装的 Hermes、其他酒馆或 ClawChat 客户端；也不会删除 ClawChat 云端联系人、撤销服务商 Key，或删除用户自行存放在下载目录的原始安装包。

## Windows

使用 setup 安装版。启动器内入口与 Windows“已安装的应用”使用同一个系统卸载程序。先选择数据处理方式，再由系统卸载程序完成清理及快捷方式移除。

正常覆盖升级会跳过此清理流程，不删除运行环境及用户数据。zip/portable 不是带系统卸载程序的安装版。

清理失败会保留应用供重试，错误详情在系统临时目录的 `nora-uninstall-result.json`，其中不包含 Key 内容。

## macOS

Apple 芯片与 Intel 使用同一流程。请从已复制到本机的 App 发起卸载，不要在 DMG 内直接卸载。

确认后启动器退出，由辅助进程清理文件及 App，结束时显示结果。直接把 App 拖入废纸篓不会触发数据清理。没有目录写入权限时会报告失败，不会自动提升权限。

## 验证范围

当前为源码实现，尚未重新发布三端安装包。

- 清理核心：保留数据、彻底删除、符号链接边界、长路径、重复执行及归属变化测试。
- 恢复：重新释放 Hermes 运行时后，读取原有配置与记忆，不覆盖新程序文件；恢复酒馆原有运行配置。
- 安全门：取消、二次确认、服务停止失败时不生成删除计划。
- Windows：在 `LongPathsEnabled=0` 的 Windows 机器上执行隔离文件测试；NSIS 钩子另有编译测试。
- macOS：使用临时 Electron App 验证辅助进程删除自己的 App 和临时数据，原 App 不变。

仍需在新构建的三个安装包上手动验收系统卸载界面、取消、保留后重装和覆盖升级。这些不由单元测试替代。
