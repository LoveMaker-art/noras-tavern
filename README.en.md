# Nora Tavern

Nora Tavern organizes persistent roleplay into Worlds and Story Sessions. Nora is a Hermes-based companion that uses MCP to work with Tavern and perform user-authorized model and core maintenance operations.

This repository owns Nora content, Tavern, MCP, Story Profile, and core installation, lifecycle and update code.

- [Install Tavern](docs/install-tavern.md)
- [Install Nora and Tavern](docs/install-nora-tavern.md)
- [Core updates and recovery](docs/update-nora-tavern.md)
- [Development, tests and construction](CONTRIBUTING.md)
- [Repository map](docs/REPOSITORY.md)

Use real Node.js 24, npm, Python 3.11+ and tar. Install the root development lock and fetch the immutable maintenance input before running source consumers. Neither an adjacent repository nor installed desktop tooling is a prerequisite. User credentials, configuration, stories and backups remain outside source control.
